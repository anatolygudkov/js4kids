Игра в интернете

До сих пор игра жила только в папке kod на твоём компьютере. Сегодня мы выложим её в интернет, и в неё сможет сыграть кто угодно по ссылке: друзья, бабушка, одноклассники. Поможет нам бесплатный сервис GitHub Pages.

В этом уроке ты:
  • подготовишь файл index.html для публикации;
  • вместе со взрослым создашь хранилище на сайте GitHub;
  • загрузишь туда игру и включишь GitHub Pages;
  • получишь ссылку на свою игру;
  • придумаешь, как улучшить игру дальше.

По правилам GitHub завести свой аккаунт можно только с 13 лет. Поэтому используйте аккаунт взрослого (свой или созданный для этого на ваш email) и проходите урок вместе с ребёнком. Нужен интернет.

Git и терминал не понадобятся: файл загружается через сайт, кнопкой. Сайт GitHub на английском, поэтому ниже рядом с каждой кнопкой дан перевод. Если интерфейс GitHub к этому времени немного изменится, ищите кнопки с теми же названиями.

Опубликованная игра будет видна всем. Проверьте, что в ней нет личных данных: фамилии, адреса, школы.

Что такое GitHub

GitHub — это сайт, где программисты со всего мира хранят свои программы. Каждая программа лежит в своём хранилище (по-английски repository, или коротко «репозиторий»). Это как папка в интернете.

GitHub Pages — услуга GitHub, которая превращает такое хранилище в настоящий сайт со своей ссылкой. Наша игра — это HTML-страница, так что она отлично подходит!

Шаг 1. Готовим файл

Сайт, открытый по ссылке, первым делом ищет страницу с именем index.html («главная страница»). Сделаем копию игры с таким именем:

  1. Открой в Geany snake.html.
  2. Файл → Сохранить как (Ctrl + Shift + S), папка kod, имя index.html. Нажми Сохранить.
  3. Теперь в Geany открыт index.html. Закрой эту вкладку: свою игру ты и дальше будешь менять в snake.html, а index.html — только копия для интернета.

Загляни в папку kod: в ней теперь три файла — proba.html, snake.html и index.html.

Шаг 2. Создаём хранилище

  1. Открой в браузере сайт github.com и войди в аккаунт (Sign in — «войти»). Это делает взрослый.
  2. В правом верхнем углу нажми + и выбери New repository («новое хранилище»).
  3. В поле Repository name («имя хранилища») напиши snake.
  4. Проверь, что выбрано Public («открытое для всех»): GitHub Pages бесплатно работает с открытыми хранилищами.
  5. Нажми зелёную кнопку Create repository («создать хранилище»).

Шаг 3. Загружаем игру

  1. На странице нового пустого хранилища найди ссылку uploading an existing file («загрузить существующий файл») и нажми на неё. (Если хранилище не пустое: кнопка Add file → Upload files.)
  2. Нажми choose your files («выбрать файлы»), открой Документы → kod и выбери index.html. Можно и просто перетащить файл мышкой из папки в окно браузера.
  3. Внизу страницы нажми зелёную кнопку Commit changes («сохранить изменения»).

Теперь в списке файлов хранилища виден index.html. Твой код лежит в интернете!

Шаг 4. Включаем GitHub Pages

  1. Вверху страницы хранилища нажми вкладку Settings («настройки», значок шестерёнки).
  2. В меню слева найди и нажми Pages.
  3. В разделе Build and deployment («сборка и публикация»), в поле Source («источник»), выбери Deploy from a branch («публиковать из ветки»).
  4. В поле Branch («ветка») выбери main, рядом оставь папку / (root). Нажми Save («сохранить»).
  5. Подожди одну-две минуты и обнови страницу (F5). Вверху появится надпись Your site is live at… («Твой сайт работает по адресу…») и кнопка Visit site («открыть сайт»).

Адрес будет таким:

https://ИМЯ-АККАУНТА.github.io/snake/

Нажми Visit site, и вот она, твоя Змейка в интернете! 🎉🐍 Скопируй ссылку из адресной строки и отправь друзьям.

💡 Рекорд в интернете У игры в интернете свой рекорд, отдельный от рекорда в папке kod. И у каждого игрока на его компьютере тоже свой: localStorage живёт в том браузере, где играют.

Как обновить игру

Если ты что-то улучшишь в игре:

  1. Поменяй и проверь snake.html как обычно.
  2. Снова сохрани его как index.html через «Сохранить как». Geany спросит, заменить ли файл, — соглашайся. Закрой вкладку index.html.
  3. На GitHub, в хранилище snake: Add file → Upload files, выбери новый index.html и нажми Commit changes. Старый файл заменится новым.
  4. Подожди минуту-две и обнови страницу игры.
⚠️ Если не работает
  • Страница 404 (не найдено)? Подожди ещё пару минут, GitHub Pages включается не мгновенно. Проверь, что файл называется именно index.html, маленькими буквами.
  • Вместо игры — список файлов или текст кода? Проверь, что в настройках Pages выбрана ветка main и папка / (root).
  • Игра открылась, но не работает? Открой консоль (F12) — ты уже умеешь читать ошибки!

Бонус: играем на телефоне

Ссылку можно открыть и на телефоне, но там нет клавиатуры со стрелками. Добавим кнопки на экран! Здесь есть хитрость: функции onKey нужно только event.key, поэтому кнопка может вызвать её сама и «притвориться» клавишей.

Добавь в snake.html под подсказкой <p class="help">:

<p>
  <button onclick="onKey({ key: 'ArrowUp' })">Вверх</button>
</p>
<p>
  <button onclick="onKey({ key: 'ArrowLeft' })">Влево</button>
  <button onclick="onKey({ key: ' ' })">Старт</button>
  <button onclick="onKey({ key: 'ArrowRight' })">Вправо</button>
</p>
<p>
  <button onclick="onKey({ key: 'ArrowDown' })">Вниз</button>
</p>
  • <button> — кнопка;
  • onclick — что делать при нажатии на кнопку (это тоже событие, как keydown);
  • { key: 'ArrowUp' } — мы сами сделали объект, похожий на настоящее событие. Внутри двойных кавычек текст пишем в одинарных кавычках '…', чтобы кавычки не перепутались.

И немного CSS в <style>, чтобы кнопки было удобно нажимать пальцем, а поле помещалось на узком экране:

    button {
      font-size: 20px;
      width: 110px;
      height: 56px;
      margin: 4px;
    }
    canvas {
      max-width: 90%;
    }

Проверь на компьютере, что кнопки работают, потом обнови index.html на GitHub и открой ссылку на телефоне.
