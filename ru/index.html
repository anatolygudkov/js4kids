Пишем игру «Змейка» на JavaScript

Привет! За этот курс ты строчка за строчкой напишешь настоящую компьютерную игру — Змейку. Её можно будет показать друзьям и даже выложить в интернет.

Что нужно:
  • компьютер Raspberry Pi с системой Raspberry Pi OS, монитор, клавиатура и мышь;
  • редактор Geany (как его найти или установить, расскажем в уроке 0);
  • браузер Firefox (он уже есть в Raspberry Pi OS);
  • желание, терпение и чуть-чуть смелости, чтобы ошибаться. Ошибки — это нормально!
👨‍👩‍👧 Для взрослых

Курс рассчитан на ребёнка примерно 10 лет, который никогда не программировал и ещё не знаком ни с Linux, ни с редакторами кода. Терминал не нужен: всё делается мышкой, в редакторе и браузере. Все файлы лежат в одной папке, а сама игра — в одном файле snake.html. Оформление (CSS) нарочно отложено до готовой игры: сначала учимся программировать, украшаем в конце. Всё работает локально, без git и без интернета; интернет понадобится только в последнем уроке, где игру выкладывают на GitHub Pages через сайт.

  • Одно занятие — один урок, 40–60 минут. В начале каждого урока есть план по минутам. Если ребёнок устал, лучше остановиться на половине и продолжить в следующий раз.
  • Код нужно набирать руками, а не копировать. Так запоминаются и сами команды, и символы на клавиатуре. Опечатки и их поиск тоже входят в обучение.
  • Не подсказывайте сразу. Сначала спросите: «Что написано в консоли? Какая строка?» Учиться искать ошибки так же важно, как писать код.
  • Задания со звёздочкой ⭐ необязательные — это для тех, кому интересно ещё.
