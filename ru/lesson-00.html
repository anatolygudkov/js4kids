Урок 0 из 16 ⏱ 45–60 минут

Готовим компьютер

Прежде чем писать игру, приготовим рабочее место: узнаем, как устроен рабочий стол, где на клавиатуре прячутся скобки, создадим папку для своих программ и настроим редактор кода.

В этом уроке ты:
  • познакомишься с рабочим столом Raspberry Pi OS;
  • научишься переключать раскладку клавиатуры и найдёшь «программистские» символы;
  • создашь папку kod для своих программ;
  • откроешь и настроишь редактор Geany;
  • расставишь окна редактора и браузера так, чтобы было удобно работать.

👨‍👩‍👧 Для взрослых: перед первым уроком

Нужна Raspberry Pi OS с рабочим столом (with desktop). Если система ещё не установлена, запишите её на карту памяти программой Raspberry Pi Imager с сайта raspberrypi.com. Удобно сразу создать для ребёнка отдельного пользователя.

В настройках клавиатуры добавьте две раскладки, английскую (US) и русскую, и выберите удобное сочетание клавиш для переключения. Это делается в Меню → Параметры → Control Centre / Настройка Raspberry Pi, раздел клавиатуры или локализации (в разных версиях системы названия немного отличаются).

Этот урок лучше пройти вместе с ребёнком.

1. Рабочий стол

Включи Raspberry Pi и подожди, пока появится рабочий стол — экран с картинкой и полоской сверху. Эта полоска называется панелью задач.

  • В левом углу панели есть значок малины 🍓. Это Меню: там все программы, разложенные по разделам.
  • Рядом — значки самых нужных программ: браузер (с ним ходят в интернет), файловый менеджер (значок папки) и терминал (чёрный экранчик). Терминал нам не понадобится.
  • Справа на панели — часы, громкость, сеть и, если взрослые добавили, значок раскладки клавиатуры (EN или RU).
💡 Как управляться с окнами У каждой открытой программы есть окно. Вверху окна — заголовок с названием и тремя кнопками справа: — спрятать, □ развернуть на весь экран, × закрыть. Чтобы передвинуть окно, тяни его мышкой за заголовок. Чтобы изменить размер — тяни за край или угол окна.

2. Клавиатура программиста

Программы пишут английскими буквами и множеством разных символов: ( ) { } [ ] ; " = < >. Русские буквы можно писать только внутри кавычек — например, в тексте, который увидит игрок.

Переключение раскладки

Раскладка — это язык, на котором печатает клавиатура. Её переключают сочетанием клавиш: чаще всего Alt + Shift или Ctrl + Shift (зажми первую клавишу и, не отпуская, нажми вторую). Спроси у взрослых, какое сочетание настроено у тебя. Какая раскладка сейчас включена, видно на значке справа вверху: EN или RU.

⚠️ Самая частая ошибка новичков Код случайно написан в русской раскладке: вместо { получилась Х, вместо ; — ж. Если в программе появились странные русские буквы, переключи раскладку на EN.

Где прячутся символы (в английской раскладке)

На многих клавиатурах нарисованы и английские, и русские буквы. Вот где искать нужные символы. Запись Shift + 9 означает «зажми Shift и нажми 9».

Важные клавиши

  • Enter — новая строка.
  • Backspace — стереть символ слева от курсора, Delete — справа.
  • Tab — сделать отступ (сдвинуть строку вправо).
  • Стрелки ← ↑ → ↓ — двигать курсор (мигающую палочку) по тексту.
  • Ctrl + Z — отменить последнее действие. Твоя волшебная кнопка «назад»!
🎯 Тренировка (5 минут) Открой Меню → Стандартные → Текстовый редактор (или любой другой редактор текста) и напечатай в английской раскладке: 
( ) { } [ ] < > ; : " ' = + * !
Потом закрой редактор. На вопрос «Сохранить?» можно ответить «Нет»: это была просто тренировка.

3. Папка для программ

Компьютер хранит всё в файлах: картинки, музыку, программы. Файлы лежат в папках, как листочки в ящиках стола. Сделаем себе один ящик для всех программ из этого курса.

  1. Нажми на значок файлового менеджера (папка) на панели задач. Откроется твоя домашняя папка. Это твоё личное место на компьютере, внутри уже есть папки «Документы», «Загрузки» и другие.
  2. Нажми правой кнопкой мыши на пустое место в окне (не на папку).
  3. В меню выбери Создать… → Папку (по-английски Create New… → Folder).
  4. Напиши имя kod и нажми Enter или OK.

Готово: рядом с другими папками появилась папка kod. Все программы из курса будут лежать в ней.

💡 Почему имя английскими буквами? Программы лучше понимают имена файлов и папок, написанные маленькими латинскими буквами, без пробелов. Мы всегда будем называть файлы так: proba.html, snake.html.

4. Редактор кода Geany

Код можно писать в любом текстовом редакторе, но удобнее в специальном редакторе для программистов. Он раскрашивает код, нумерует строки и сам ставит отступы. Мы возьмём Geany (читается «джини»): он простой и быстро работает на Raspberry Pi.

Найди Geany

Открой Меню 🍓 → Программирование. Если там есть Geany, отлично, переходи к настройке.

Если Geany нет, его надо установить (позови взрослого, может понадобиться пароль):

  1. Меню → Параметры → Рекомендуемое ПО (Preferences → Recommended Software).
  2. Слева выбери раздел Программирование (Programming).
  3. Найди в списке Geany и поставь галочку.
  4. Нажми Применить (Apply) и подожди, пока закончится установка.
👨‍👩‍👧 Для взрослых Если программы «Рекомендуемое ПО» в меню нет, установите Geany через терминал командой sudo apt install geany.

Настроим Geany

Открой Geany: Меню → Программирование → Geany. Названия пунктов меню ниже даны по-русски и в скобках по-английски: на твоём компьютере может быть любой вариант.

  1. Крупный шрифт. Правка → Настройки (Edit → Preferences) → вкладка Интерфейс (Interface) → Шрифты (Fonts) → строка Редактор (Editor). Нажми на кнопку со шрифтом и поставь размер 16 или 18. Ещё можно увеличить шрифт кнопками Ctrl + + и уменьшить кнопками Ctrl + -.
  2. Отступы. В тех же настройках: вкладка Редактор (Editor) → Отступы (Indentation). Поставь Ширина: 2 (Width) и Тип: Пробелы (Type: Spaces). Нажми OK.
  3. Убираем лишнее. В меню Вид (View) сними галочки с пунктов Показать боковую панель (Show Sidebar) и Показать окно сообщений (Show Message Window). Так останется только место для кода.
  4. Номера строк. Слева от текста должны быть номера строк: 1, 2, 3… Если их нет, включи их в Вид → Показывать номера строк (View → Show Line Numbers).
💡 Не бойся нажимать Если что-то в редакторе пропало или выглядит странно, ничего не сломалось. Закрой Geany и открой его снова или попроси взрослого помочь.

5. Браузер

Наши программы будет запускать браузер — та же программа, в которой открывают сайты. Мы будем пользоваться Firefox — у него значок с оранжевой лисой. Найди его на панели задач или в Меню → Интернет и открой.

👨‍👩‍👧 Для взрослых Сделайте Firefox браузером по умолчанию, чтобы файлы .html открывались в нём двойным щелчком. В Raspberry Pi OS это делается в Меню → Параметры → Control Centre / Настройка Raspberry Pi, вкладка System, пункт Browser → Firefox. Если Firefox не установлен, он есть в Рекомендуемом ПО (раздел Internet).

6. Расставляем окна

Программисты постоянно смотрят то в код, то на результат. Поставь окна рядом: Geany слева, браузер справа. Перетащи их за заголовки и подвинь края, чтобы каждое занимало половину экрана.

Проверь себя

  • Я знаю, как переключить раскладку, и умею набрать { } ( ) ; ".
  • В моей домашней папке есть папка kod.
  • Geany открывается, шрифт крупный, отступ — 2 пробела.
  • Я умею открыть Firefox и поставить окна рядом.
