Готовим компьютер

Прежде чем писать игру, приготовим рабочее место: поставим редактор кода и браузер, создадим папку для своих программ и найдём на клавиатуре все скобки. Курс подходит для любого компьютера — с Windows, macOS или Linux.

В этом уроке ты:
  • узнаешь, какая система стоит на твоём компьютере, и найдёшь в ней нужные программы;
  • создашь папку kod для своих программ;
  • установишь и настроишь редактор Geany и браузер Firefox;
  • найдёшь на клавиатуре «программистские» символы;
  • расставишь окна так, чтобы было удобно работать.

Подойдёт любой компьютер: с Linux (например, Raspberry Pi OS или Ubuntu), macOS или Windows. Мы ставим две бесплатные программы, которые одинаково выглядят на всех системах: редактор Geany и браузер Firefox. Поэтому все остальные уроки одинаковы для всех, отличается только этот.

Этот урок лучше пройти вместе с ребёнком: для установки программ могут понадобиться пароль и права администратора. Удобно сразу создать для ребёнка отдельного пользователя.

1. Какой у тебя компьютер?

На каждом компьютере работает операционная система — главная программа, которая показывает рабочий стол, окна и меню. Самые известные: Windows, macOS (на компьютерах Apple) и Linux (например, на маленьких компьютерах Raspberry Pi или с системой Ubuntu).

Ниже — разделы для каждой системы. Раздел твоей системы обычно открывается сам. Если нет — открой его щелчком. Остальные разделы читать не нужно.

💡 Как управляться с окнами (на любой системе) У каждой открытой программы есть окно. Вверху окна — заголовок с названием и кнопками: свернуть, развернуть на весь экран и закрыть (×). Чтобы передвинуть окно, тяни его мышкой за заголовок. Чтобы изменить размер — тяни за край или угол окна.
🍓 Raspberry Pi OS (Linux)

Рабочий стол

Вверху экрана — панель задач. В её левом углу значок малины 🍓 — это Меню со всеми программами. Рядом — значки браузера и файлового менеджера (папка).

Раскладка клавиатуры

Взрослые добавляют раскладки English (US) и Русская в Меню → Параметры → Control Centre / Настройка Raspberry Pi, раздел клавиатуры. Там же выбирают сочетание для переключения, например Alt + Shift. Какая раскладка включена, видно на значке EN / RU на панели.

Папка для программ

  1. Нажми значок файлового менеджера на панели и открой папку Документы (Documents).
  2. Щёлкни правой кнопкой мыши на пустом месте и выбери Создать… → Папку (Create New… → Folder).
  3. Назови её kod и нажми Enter.

Geany и Firefox

Geany часто уже есть: Меню → Программирование → Geany. Firefox — в Меню → Интернет. Если какой-то программы нет:

  1. Меню → Параметры → Рекомендуемое ПО (Recommended Software).
  2. Geany — в разделе Программирование, Firefox — в разделе Интернет. Поставь галочку.
  3. Нажми Применить (Apply) и подожди окончания установки.
👨‍👩‍👧 Для взрослыхЧерез терминал: sudo apt install geany firefox. Браузер по умолчанию выбирается в Control Centre, вкладка System, пункт Browser.
🐧 Ubuntu и другие Linux

Рабочий стол

Слева или внизу — док со значками программ. Кнопка Показать приложения (квадрат из точек) открывает все программы; там есть поиск — просто начни печатать название. Папки открывает программа Файлы.

Раскладка клавиатуры

Взрослые добавляют Русскую раскладку: Настройки → Клавиатура → Источники ввода → +. Переключение — Super + Пробел (Super — клавиша с логотипом между Ctrl и Alt). Значок en / ru — в правом верхнем углу.

Папка для программ

  1. Открой Файлы и зайди в папку Документы.
  2. Щёлкни правой кнопкой на пустом месте → Новая папка.
  3. Назови её kod и нажми Создать.

Geany и Firefox

Firefox в Ubuntu уже установлен. Geany ставится так:

  1. Открой Центр приложений (App Center или Ubuntu Software).
  2. Найди Geany через поиск и нажми Установить. Попросят пароль — позови взрослого.
  3. Запускай Geany через Показать приложения: просто начни печатать «geany».
👨‍👩‍👧 Для взрослыхЧерез терминал: sudo apt install geany (в Fedora — sudo dnf install geany). Браузер по умолчанию: Настройки → Приложения по умолчанию → Веб.
🍏 macOS (компьютеры Apple)

Рабочий стол

Внизу экрана — Dock со значками программ. Любую программу легко найти поиском Spotlight: нажми ⌘ Cmd + Пробел и начни печатать название. Папки открывает Finder (синий улыбающийся значок).

Раскладка клавиатуры

Взрослые добавляют раскладку: Системные настройки → Клавиатура → Источники ввода → Изменить → +. Выбирайте Русская — ПК: в ней символы стоят так же, как на обычной русской клавиатуре, и таблица ниже подходит. Для кода нужна раскладка ABC или U.S.. Переключение — Ctrl + Пробел или клавиша 🌐 (fn).

Папка для программ

  1. Открой Finder и выбери слева Документы.
  2. Щёлкни правой кнопкой (или Ctrl + щелчок) на пустом месте → Новая папка.
  3. Назови её kod и нажми Return.

Geany и Firefox

  1. Geany: на сайте geany.org открой Download → Releases и скачай файл для macOS (.dmg). Открой его и перетащи значок Geany в папку Программы.
  2. Firefox: скачай с сайта mozilla.org и тоже перетащи в Программы.
  3. Если при первом запуске macOS не даёт открыть программу, щёлкни по ней в папке Программы правой кнопкой → Открыть → Открыть. Или: Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
⌘ На Mac вместо Ctrl — Cmd В уроках написано Ctrl + S, а на Mac нажимай ⌘ Cmd + S. Так же с N, O, Z, +. В браузере обновить страницу — ⌘ + R (вместо F5), консоль — ⌘ + ⌥ Option + K. Полная таблица — в шпаргалке.
👨‍👩‍👧 Для взрослыхС Homebrew: brew install --cask geany firefox. Браузер по умолчанию: Системные настройки → Рабочий стол и Dock → Веб-браузер по умолчанию.
🪟 Windows

Рабочий стол

Внизу экрана — панель задач. Кнопка Пуск (значок Windows) открывает все программы, там есть поиск — просто начни печатать название. Папки открывает Проводник (жёлтая папка).

Раскладка клавиатуры

Русская и английская раскладки обычно уже есть. Переключение — Win + Пробел или Alt + Shift. Значок ENG / РУС — справа внизу, возле часов.

Папка для программ

  1. Открой Проводник и выбери слева Документы.
  2. Щёлкни правой кнопкой на пустом месте → Создать → Папку.
  3. Назови её kod и нажми Enter.
⚠️ Включи показ расширений Windows прячет окончания имён файлов, и вместо proba.html ты увидишь просто proba. Включи их: в Проводнике Вид → Показать → Расширения имён файлов (в Windows 10: вкладка Вид → галочка Расширения имён файлов).

Geany и Firefox

  1. Geany: на сайте geany.org открой Download → Releases и скачай установщик для Windows (файл, который кончается на _setup.exe). Запусти его и нажимай Далее, оставляя всё как есть.
  2. Firefox: скачай с сайта mozilla.org и установи так же.
  3. Обе программы появятся в меню Пуск.
👨‍👩‍👧 Для взрослыхСкачивайте программы только с официальных сайтов. Через терминал: winget install Geany.Geany Mozilla.Firefox. Браузер по умолчанию: Параметры → Приложения → Приложения по умолчанию → Firefox.

2. Клавиатура программиста

Программы пишут английскими буквами и множеством разных символов: ( ) { } [ ] ; " = < >. Русские буквы можно писать только внутри кавычек — например, в тексте, который увидит игрок.

Раскладка — это язык, на котором печатает клавиатура. Как её переключать на твоей системе, написано в разделе выше.

⚠️ Самая частая ошибка новичков Код случайно написан в русской раскладке: вместо { получилась Х, вместо ; — ж. Если в программе появились странные русские буквы, переключи раскладку на английскую.

Где прячутся символы (в английской раскладке)

На многих клавиатурах нарисованы и английские, и русские буквы. Вот где искать нужные символы. Запись Shift + 9 означает «зажми Shift и нажми 9».

Важные клавиши

  • Enter — новая строка (на Mac эта клавиша называется Return).
  • Backspace — стереть символ слева от курсора, Delete — справа.
  • Tab — сделать отступ (сдвинуть строку вправо).
  • Стрелки ← ↑ → ↓ — двигать курсор (мигающую палочку) по тексту.
  • Ctrl + Z (на Mac ⌘ + Z) — отменить последнее действие. Твоя волшебная кнопка «назад»!

3. Настраиваем Geany

Код можно писать в любом текстовом редакторе, но удобнее в специальном редакторе для программистов. Он раскрашивает код, нумерует строки и сам ставит отступы. Мы взяли Geany (читается «джини»): он простой, бесплатный и выглядит одинаково на всех системах.

Открой Geany. Названия пунктов меню ниже даны по-русски и в скобках по-английски: на твоём компьютере может быть любой вариант.

  1. Крупный шрифт. Правка → Настройки (Edit → Preferences; на Mac настройки могут быть в меню Geany) → вкладка Интерфейс (Interface) → Шрифты (Fonts) → строка Редактор (Editor). Поставь размер 16 или 18. Ещё шрифт увеличивают кнопками Ctrl + + и уменьшают кнопками Ctrl + -.
  2. Отступы. В тех же настройках: вкладка Редактор (Editor) → Отступы (Indentation). Поставь Ширина: 2 (Width) и Тип: Пробелы (Type: Spaces). Нажми OK.
  3. Убираем лишнее. В меню Вид (View) сними галочки с пунктов Показать боковую панель (Show Sidebar) и Показать окно сообщений (Show Message Window). Так останется только место для кода.
  4. Номера строк. Слева от текста должны быть номера строк: 1, 2, 3… Если их нет, включи Вид → Показывать номера строк (View → Show Line Numbers).
🎯 Тренировка (5 минут) Создай в Geany новый файл (Файл → Создать) и напечатай в английской раскладке: 
( ) { } [ ] < > ; : " ' = + * !
Потом закрой вкладку. На вопрос «Сохранить?» ответь «Нет»: это была просто тренировка.
💡 Не бойся нажимать Если что-то в редакторе пропало или выглядит странно, ничего не сломалось. Закрой Geany и открой его снова или попроси взрослого помочь.
👨‍👩‍👧 Для взрослых: альтернативы Geany

Мы выбрали Geany, потому что он лёгкий, бесплатный и одинаковый на Windows, macOS и Linux — так проще объяснять. Если хочется другой редактор:

  • Visual Studio Code (или его открытая сборка VSCodium) — самый популярный редактор у программистов, есть на всех системах. Очень мощный, но в нём много панелей и подсказок, поэтому на него лучше перейти после курса. На Raspberry Pi заметно медленнее Geany.
  • Notepad++ (только Windows) — лёгкий и похожий на Geany.
  • Kate или Текстовый редактор (gedit, GNOME Text Editor) в Linux — подсветка кода есть, но удобств меньше.
  • CotEditor (только macOS) — простой бесплатный редактор кода.

Не подходят: Блокнот в Windows и TextEdit в macOS — в них нет подсветки и номеров строк, а TextEdit по умолчанию сохраняет форматированный текст, который браузер не поймёт. Word и другие текстовые процессоры не подходят тоже.

4. Расставляем окна

Наши программы будет запускать Firefox — та же программа, в которой открывают сайты. Программисты постоянно смотрят то в код, то на результат. Поставь окна рядом: Geany слева, Firefox справа. Перетащи их за заголовки и подвинь края, чтобы каждое заняло половину экрана.

💡 Быстрый способ В Windows и Ubuntu окно можно прижать к половине экрана: Win (Super) + ← или →. На Mac — подержи курсор на зелёной кнопке в углу окна и выбери расположение.

Проверь себя

  • Я знаю, какая система на моём компьютере.
  • В папке «Документы» есть папка kod.
  • Geany открывается, шрифт крупный, отступ — 2 пробела.
  • Firefox установлен, и я умею поставить окна рядом.
  • Я умею переключать раскладку и набрать { } ( ) ; ".
