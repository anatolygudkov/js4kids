H4 Напиши код ⭐⭐ 

    
Допиши функцию wrap(n) для порталов: если n вышло за поле 0…19, верни его с другой стороны. Должно вывести 0, 19 и 7.

    
 

    
✅ Показать ответ
Те же два if, что в порталах урока 9, только упакованные в функцию. Теперь её можно вызывать и для x, и для y.
let cells = 20;

function wrap(n) {
  if (n >= cells) {
    n = 0;
  }
  if (n < 0) {
    n = cells - 1;
  }
  return n;
}

console.log(wrap(20));
console.log(wrap(-1));
console.log(wrap(7));
