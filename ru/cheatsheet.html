Переменные и действия

let score = 0;              // создать коробку
score = score + 1;          // изменить (без let!)
score++;                    // то же самое короче
let text = "Счёт: " + score; // склеить текст
// + - * /  — плюс, минус, умножить, разделить

Условия

if (score > 10) {
  // если правда
} else {
  // иначе
}
// сравнения: >  <  >=  <=  ===  !==
// и: &&     или: ||     не: !

Объекты и массивы

let apple = { x: 15, y: 10 };    // объект
apple.x = 3;

let snake = [{ x: 1, y: 1 }, { x: 0, y: 1 }];  // массив
snake[0]          // первый элемент (номера с нуля!)
snake.length      // сколько элементов
snake.push(a)     // добавить в конец
snake.unshift(a)  // добавить в начало
snake.pop()       // убрать последний

Холст

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
ctx.fillStyle = "red";                 // цвет
ctx.fillRect(x, y, width, height);     // прямоугольник
ctx.font = "32px sans-serif";          // шрифт
ctx.fillText("Текст", x, y);           // текст

(0, 0) — левый верхний угол. x растёт вправо, y — вниз.

Частые ошибки

СообщениеЧто проверить
… is not definedопечатка в имени, большие/маленькие буквы, текст без кавычек
missing ) after argument listне хватает )
missing } after function bodyне хватает } в конце функции, if или цикла
string literal contains an unescaped line breakнезакрытая кавычка
expected …, got … / illegal characterлишний или странный символ, русская буква вместо символа
redeclaration of let …let написан дважды для одной переменной
