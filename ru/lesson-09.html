Условия

Змейка уползает за край поля. Нужно, чтобы программа умела решать: если змейка у края, то сделать что-то особенное. Для этого есть команда if. С её помощью мы сделаем волшебные порталы: змейка уползает в одну стену и выползает из противоположной.

В этом уроке ты:
  • узнаешь, что такое true и false;
  • научишься сравнивать числа: >, <, === и другие;
  • напишешь условия if и if … else;
  • соединишь условия словами «и» (&&) и «или» (||);
  • сделаешь порталы по краям поля.

Правда или ложь?

Открой консоль и задай компьютеру вопросы:

5 > 3
2 > 7
10 === 10
10 === 11

На каждый вопрос компьютер отвечает true (правда) или false (ложь). Вот все способы сравнивать:

ЗнакВопросПример
>больше?5 > 3 → true
<меньше?5 < 3 → false
>=больше или равно?20 >= 20 → true
<=меньше или равно?0 <= -1 → false
===равно?7 === 7 → true
!==не равно?7 !== 7 → false
⚠️ Одно, два или три «равно»? = (одно) — «положи в коробку». === (три) — вопрос «равны ли?». Не путай их! В нашем курсе для сравнения всегда пишем три знака равенства.

Если… то… иначе

let score = 12;

if (score > 10) {
  console.log("Ты молодец!");
}

В круглых скобках после if («если») — вопрос. Если ответ true, выполняется то, что в фигурных скобках. Если false — пропускается.

А с помощью else («иначе») можно сказать, что делать, когда ответ «нет»:

if (score > 10) {
  console.log("Ты молодец!");
} else {
  console.log("Попробуй ещё раз!");
}

Поменяй score на 5 и проверь, что выведется. Можешь поэкспериментировать в proba.html.

Волшебные порталы

Поле — от клеточки 0 до клеточки 19. Голова змейки вышла за край, если:

  • head.x >= cells — ушла за правый край (x стал 20);
  • head.x < 0 — ушла за левый край (x стал -1);
  • head.y >= cells — ушла за нижний край;
  • head.y < 0 — ушла за верхний край.

В каждом случае перенесём голову к противоположной стене. Добавь проверки в функцию step: после того как создали head, но до unshift.

function step() {
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };

  if (head.x >= cells) {
    head.x = 0;
  }
  if (head.x < 0) {
    head.x = cells - 1;
  }
  if (head.y >= cells) {
    head.y = 0;
  }
  if (head.y < 0) {
    head.y = cells - 1;
  }

  snake.unshift(head);
  snake.pop();
  draw();
}

Сохрани, обнови и смотри: змейка доползает до правого края и выползает слева. Порталы работают!

Поменяй в начале программы dx и dy, чтобы проверить все четыре портала.

💡 Почему cells - 1? cells равно 20, а последняя клеточка имеет номер 19. Поэтому из левой стены выходим на клеточку cells - 1, то есть 19.

«И» и «или»

Иногда нужно проверить два условия сразу:

  • && — «и»: правда, только если оба условия правда.
  • || — «или»: правда, если хотя бы одно условие правда.
let x = 5;
console.log(x > 0 && x < 10);    // true: x больше 0 И меньше 10
console.log(x < 0 || x > 3);     // true: хотя бы одно верно
console.log(x < 0 || x > 100);   // false: оба неверны

Символ & — это Shift + 7, а | — Shift + \. Оба знака пишутся по два раза. Эти «и» и «или» понадобятся нам уже в следующем уроке.

📄 Весь файл snake.html после этого урока 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Змейка</title>
</head>
<body>
  <h1>Змейка</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x >= cells) {
        head.x = 0;
      }
      if (head.x < 0) {
        head.x = cells - 1;
      }
      if (head.y >= cells) {
        head.y = 0;
      }
      if (head.y < 0) {
        head.y = cells - 1;
      }

      snake.unshift(head);
      snake.pop();
      draw();
    }

    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
