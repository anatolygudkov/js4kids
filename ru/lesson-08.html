Змейка ползёт

Мультфильм — это много картинок, которые быстро сменяют друг друга. Наша игра будет работать так же: несколько раз в секунду сдвигать змейку и рисовать новую картинку. Сегодня змейка оживёт!

В этом уроке ты:
  • узнаешь хитрый способ двигать змейку: голову вперёд, хвост долой;
  • познакомишься с командами массивов unshift и pop;
  • запустишь таймер setInterval;
  • научишься задавать направление переменными dx и dy.

Как ползает змейка

Можно сдвигать каждый кусочек змейки по очереди, но есть способ проще. Смотри: чтобы змейка проползла на одну клеточку, достаточно:

  1. добавить новую голову на клеточку впереди;
  2. убрать последний кусочек хвоста.

Для этого у массивов есть готовые команды:

  • snake.unshift(что-то) — добавить элемент в начало списка (на место номер 0);
  • snake.pop() — убрать последний элемент списка.
💡 Проверь в консоли Открой snake.html, нажми F12 и введи по очереди: 
snake.unshift({ x: 11, y: 10 });
snake.pop();
draw();
Змейка сдвинулась на одну клеточку вправо! Повтори эти три строчки ещё пару раз (стрелка ↑ в консоли вызывает предыдущие команды).

Куда ползти: dx и dy

Новая голова появляется рядом со старой. Где именно, зависит от направления. Заведём две переменные:

  • dx — на сколько клеточек сдвигаться по x за один шаг;
  • dy — на сколько клеточек сдвигаться по y.
Направлениеdxdy
вправо →10
влево ←-10
вниз ↓01
вверх ↑0-1

(Помнишь, на экране y растёт вниз? Поэтому «вверх» — это -1.)

Тогда новая голова — это старая голова плюс сдвиг:

let head = { x: snake[0].x + dx, y: snake[0].y + dy };

Один шаг игры

Соберём всё в функцию step («шаг»): сделать новую голову, добавить её, убрать хвост, перерисовать.

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];
let apple = { x: 15, y: 10 };
let dx = 1;
let dy = 0;

function clearField() { ... }      // без изменений

function drawCell(x, y, color) { ... }   // без изменений

function draw() { ... }            // без изменений

function step() {
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };
  snake.unshift(head);
  snake.pop();
  draw();
}

draw();
setInterval(step, 200);
⚠️ Многоточия не набирай! Запись { ... } // без изменений значит, что функция остаётся такой же, как была. Не стирай её! Если сомневаешься, загляни в полный файл в конце урока.

Сохрани, обнови… Змейка поползла! 🎉

Таймер

setInterval(step, 200);

setInterval — «вызывай функцию step снова и снова, каждые 200 миллисекунд». Миллисекунда — это одна тысячная секунды, так что 200 миллисекунд — это пятая часть секунды. Значит, змейка делает 5 шагов в секунду.

⚠️ Без скобок! Пишем setInterval(step, 200), а не setInterval(step(), 200). Мы не вызываем step сами, а отдаём её таймеру, чтобы он вызывал её, когда придёт время.

А потом змейка уползает за край поля и исчезает… Она не пропала, её координаты просто стали больше 19, и она ползёт где-то за пределами холста. Это мы исправим в следующем уроке.

📄 Весь файл snake.html после этого урока 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Змейка</title>
</head>
<body>
  <h1>Змейка</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };
      snake.unshift(head);
      snake.pop();
      draw();
    }

    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
