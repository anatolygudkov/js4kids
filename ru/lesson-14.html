Скорость и рекорд

Игра работает, но пока слишком спокойная. Сегодня змейка будет ускоряться после каждого яблока, игра научится помнить твой рекорд даже после выключения компьютера, а ещё мы поймаем один хитрый баг.

В этом уроке ты:
  • сделаешь, чтобы змейка ускорялась;
  • сохранишь рекорд в памяти браузера с помощью localStorage;
  • найдёшь и исправишь баг с быстрым разворотом.

1. Скорость растёт

Сейчас таймер всегда срабатывает каждые 200 миллисекунд. Положим это число в переменную speed (по-английски «скорость»). На самом деле это пауза между шагами: чем число меньше, тем быстрее змейка.

Добавь переменную наверху, к остальным:

let gameOver;
let timer;
let speed;

В startGame задай начальную скорость и используй её в таймере:

  gameOver = false;
  speed = 200;
  showScore();
  placeApple();
  draw();
  timer = setInterval(step, 200);
  timer = setInterval(step, speed);
}

А когда змейка съедает яблоко, уменьшим паузу на 10 миллисекунд. Только у таймера нельзя поменять скорость на ходу, поэтому выключаем старый таймер и запускаем новый, побыстрее:

  if (head.x === apple.x && head.y === apple.y) {
    score = score + 1;
    showScore();
    placeApple();
    if (speed > 60) {
      speed = speed - 10;
      clearInterval(timer);
      timer = setInterval(step, speed);
    }
  } else {
    snake.pop();
  }

Проверка speed > 60 нужна, чтобы игра не разогналась до невозможной скорости: быстрее, чем 60 миллисекунд на шаг, змейка не станет.

2. Рекорд

Когда страницу обновляют или закрывают, все переменные исчезают: программа начинается заново. А рекорд хочется помнить всегда! Для этого у браузера есть своя маленькая память — localStorage («местное хранилище»). Это как блокнот, в который можно записать значение под каким-нибудь именем:

localStorage.setItem("snakeBest", 25);         // записать
localStorage.getItem("snakeBest");             // прочитать

Записи в этом блокноте остаются, даже если закрыть браузер и выключить компьютер.

Место для рекорда на странице

<p>Счёт: <span id="score">0</span></p>
<p>Счёт: <span id="score">0</span> | Рекорд: <span id="best">0</span></p>

Читаем рекорд при запуске

Добавь переменную наверху:

let best = Number(localStorage.getItem("snakeBest"));

Блокнот localStorage хранит всё как текст, а нам нужно число, чтобы сравнивать. Number(...) превращает текст в число. Если рекорда ещё нет, getItem вернёт null («ничего»), а Number(null) — это 0. То, что надо!

Показываем и сохраняем

Пусть showScore показывает оба числа:

function showScore() {
  document.getElementById("score").textContent = score;
  document.getElementById("best").textContent = best;
}

А в endGame, сразу после clearInterval(timer);, проверим, побит ли рекорд:

function endGame() {
  gameOver = true;
  clearInterval(timer);
  if (score > best) {
    best = score;
    localStorage.setItem("snakeBest", best);
    showScore();
  }
  ...

Сыграй, набери несколько очков и проиграй. Потом закрой вкладку и открой игру снова: рекорд на месте! 🏆

💡 Как сбросить рекорд В консоли введи localStorage.removeItem("snakeBest") и обнови страницу.

3. Охота на баг

Баг (по-английски «жучок») — так программисты называют ошибку в программе. Проведи опыт: пусть змейка ползёт вправо. Теперь очень быстро, почти одновременно, нажми ↑ и сразу ←. Иногда змейка погибает на ровном месте! Почему?

Давай разберёмся по шагам. Между двумя шагами змейки нажаты две клавиши:

  1. ↑: змейка ползёт вправо, dy не равно 1, значит, можно поворачивать. Теперь dx = 0, dy = -1. Но змейка ещё не сдвинулась!
  2. ←: проверяем dx !== 1. Сейчас dx уже 0, значит, можно. Теперь dx = -1.
  3. Наступает шаг: змейка, которая на самом деле ползла вправо, делает шаг влево, прямо в свою шею.

Исправление: будем запоминать нажатую клавишу как следующее направление, а настоящее направление менять только в начале шага. Проверять же будем по настоящему направлению.

Добавь наверху ещё две переменные:

let dx;
let dy;
let nextDx;
let nextDy;

В startGame задай им начальные значения рядом с dx и dy:

  dx = 1;
  dy = 0;
  nextDx = 1;
  nextDy = 0;

В самом начале step применяем следующее направление:

function step() {
  dx = nextDx;
  dy = nextDy;
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };

А в onKey меняем только nextDx и nextDy (проверки остаются как были):

function onKey(event) {
  if (event.key === "ArrowUp" && dy !== 1) {
    nextDx = 0;
    nextDy = -1;
  }
  if (event.key === "ArrowDown" && dy !== -1) {
    nextDx = 0;
    nextDy = 1;
  }
  if (event.key === "ArrowLeft" && dx !== 1) {
    nextDx = -1;
    nextDy = 0;
  }
  if (event.key === "ArrowRight" && dx !== -1) {
    nextDx = 1;
    nextDy = 0;
  }
  if (event.key === " " && gameOver) {
    startGame();
  }
}

Теперь в нашем примере вторая клавиша ← проверяется по настоящему направлению: dx всё ещё 1 (змейка ползёт вправо), значит, поворот налево запрещён. Баг пойман! 🐞

🎯 Задания
  1. Подбери ускорение по вкусу: может быть, уменьшать паузу на 5, а не на 10? Или самая большая скорость — 80?
  2. Когда рекорд побит, пусть в endGame под надписями появляется ещё одна: «Новый рекорд!».
  3. ⭐ Добавь «золотое» яблоко: с небольшим шансом (Math.random() < 0.2) яблоко становится золотым и даёт 5 очков. Подсказка: добавь в объект apple свойство gold со значением true или false.
📄 Весь файл snake.html после этого урока 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Змейка</title>
</head>
<body>
  <h1>Змейка</h1>
  <p>Счёт: <span id="score">0</span> | Рекорд: <span id="best">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake;
    let apple = { x: 0, y: 0 };
    let dx;
    let dy;
    let nextDx;
    let nextDy;
    let score;
    let gameOver;
    let timer;
    let speed;
    let best = Number(localStorage.getItem("snakeBest"));

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function isOnSnake(x, y) {
      for (let i = 0; i < snake.length; i++) {
        if (snake[i].x === x && snake[i].y === y) {
          return true;
        }
      }
      return false;
    }

    function showScore() {
      document.getElementById("score").textContent = score;
      document.getElementById("best").textContent = best;
    }

    function placeApple() {
      apple.x = randomCell();
      apple.y = randomCell();
      while (isOnSnake(apple.x, apple.y)) {
        apple.x = randomCell();
        apple.y = randomCell();
      }
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function endGame() {
      gameOver = true;
      clearInterval(timer);
      if (score > best) {
        best = score;
        localStorage.setItem("snakeBest", best);
        showScore();
      }
      ctx.fillStyle = "white";
      ctx.font = "32px sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("Игра окончена", 200, 200);
      ctx.font = "18px sans-serif";
      ctx.fillText("Нажми пробел, чтобы сыграть ещё", 200, 240);
    }

    function step() {
      dx = nextDx;
      dy = nextDy;
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
        endGame();
        return;
      }
      if (isOnSnake(head.x, head.y)) {
        endGame();
        return;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        showScore();
        placeApple();
        if (speed > 60) {
          speed = speed - 10;
          clearInterval(timer);
          timer = setInterval(step, speed);
        }
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        nextDx = 0;
        nextDy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        nextDx = 0;
        nextDy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        nextDx = -1;
        nextDy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        nextDx = 1;
        nextDy = 0;
      }
      if (event.key === " " && gameOver) {
        startGame();
      }
    }

    function startGame() {
      snake = [
        { x: 10, y: 10 },
        { x: 9, y: 10 },
        { x: 8, y: 10 }
      ];
      dx = 1;
      dy = 0;
      nextDx = 1;
      nextDy = 0;
      score = 0;
      gameOver = false;
      speed = 200;
      showScore();
      placeApple();
      draw();
      timer = setInterval(step, speed);
    }

    document.addEventListener("keydown", onKey);
    startGame();
  </script>
</body>
</html>
