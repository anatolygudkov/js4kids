Ponerlo bonito

El juego está listo y funciona. Ahora viene lo más divertido: ¡vamos a decorarlo! Para el aspecto de las páginas existe un tercer lenguaje, el CSS. Lo hemos dejado a propósito para el final: primero el programa tiene que funcionar, y luego se decora.

En esta lección vas a:
  • descubrir qué es el CSS y dónde se escribe;
  • cambiar el color de fondo y los tipos de letra, y poner un borde al campo;
  • aprender a elegir elementos por etiqueta, por id y por clase;
  • dibujar una manzana redonda.

Tres lenguajes en una página

  • HTML — qué hay en la página (título, puntos, campo);
  • JavaScript — cómo funciona (la serpiente se mueve, come, crece);
  • CSS — qué aspecto tiene (colores, tamaños, bordes, tipos de letra).

El CSS se escribe dentro de la etiqueta <style>, en la «cabeza» de la página, en <head>. Una regla de CSS es así:

h1 {
  color: green;
  font-size: 48px;
}
  • h1 — a quién decoramos (todos los títulos <h1>). Se llama selector;
  • entre las llaves, qué cambiamos: propiedad, dos puntos, valor, punto y coma.

Se parece mucho a los objetos de JavaScript, ¿verdad? Solo que con punto y coma en lugar de comas.

Decoramos la página

Añade en <head>, después de <title>, un bloque de estilos:

<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
  <style>
    body {
      background: #10241a;
      color: white;
      font-family: sans-serif;
      text-align: center;
    }
  </style>
</head>

Guarda y recarga: el fondo es verde oscuro, el texto es blanco y todo está centrado. Vamos a verlo:

PropiedadQué cambia
backgroundel color de fondo
colorel color del texto
font-familyel tipo de letra: sans-serif — sin remates, serif — con remates, monospace — como en un editor de código
text-alignla alineación: left, center, right
font-sizeel tamaño de la letra, por ejemplo 48px
borderel borde: grosor, tipo, color — 6px solid green
border-radiusesquinas redondeadas
marginel espacio alrededor de un elemento, por fuera
font-weightel grosor de la letra: bold — negrita
💡 Códigos de color #10241a es un color escrito en código: después de la almohadilla van tres parejas de símbolos, cuánto rojo, verde y azul tiene el color. Cada pareja va de 00 (nada) a ff (el máximo). Por ejemplo, #ff0000 es rojo y #ffff00 es amarillo. También se pueden usar nombres en inglés: green, gold, tomato.

El título y el borde

Añade dentro de <style>, después de la regla de body, dos reglas más:

    h1 {
      color: #7ee081;
      font-size: 48px;
      margin: 10px;
    }
    canvas {
      border: 6px solid #3fa34d;
      border-radius: 10px;
    }

Los puntos: elegir por id

Para decorar un elemento concreto, se elige por su nombre id con un # delante. Vamos a poner los números de los puntos y del récord en amarillo y en negrita:

    #score, #best {
      color: yellow;
      font-weight: bold;
    }

Una coma entre selectores significa «este y este».

Una pista: elegir por clase

Añade debajo del lienzo una pista para quien juega. Le daremos una clase: un nombre para el diseño. A diferencia de un id, una misma clase se puede dar a muchos elementos.

<canvas id="game" width="400" height="400"></canvas>
<p class="help">Flechas - mover, espacio - nueva partida</p>

En CSS, una clase se elige con un punto:

    .help {
      color: #9fb8a5;
    }
SelectorA quién eligeEjemplo
canvasa todos los elementos con esa etiqueta<canvas>
#scoreal único elemento con id="score"<span id="score">
.helpa todos los elementos con class="help"<p class="help">

Una manzana redonda

El CSS no decora el lienzo: en él dibuja JavaScript. Vamos a hacer redonda la manzana. Añade una función después de drawCell:

function drawApple() {
  ctx.fillStyle = "red";
  ctx.beginPath();
  ctx.arc(apple.x * size + size / 2, apple.y * size + size / 2, size / 2 - 1, 0, Math.PI * 2);
  ctx.fill();
}
  • beginPath() — «empiezo una figura nueva»;
  • arc(x, y, radio, inicio, fin) — un arco con el centro en el punto (x, y). El centro de una casilla es su esquina más la mitad de su tamaño. El radio es media casilla. Y 0 y Math.PI * 2 significan «del principio al final del círculo»: un círculo completo;
  • fill() — rellenar la figura.

En la función draw, cambia cómo se dibuja la manzana:

  drawCell(apple.x, apple.y, "red");
  drawApple();
🎯 Inventa tu propio estilo
  1. Elige tus colores para el fondo, el título y el borde. Puedes hacer una serpiente «espacial» sobre fondo azul oscuro o una «del desierto» sobre color arena.
  2. Cambia los colores de la serpiente en draw y el color del campo en clearField para que combinen con la página.
  3. Ponle sombra al título: text-shadow: 3px 3px 0 black;
  4. ⭐ Dibuja ojos a la serpiente: dos cuadraditos negros dentro de la casilla de la cabeza, después de dibujar la cabeza.
📄 El juego terminado: el archivo snake.html completo 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
  <style>
    body {
      background: #10241a;
      color: white;
      font-family: sans-serif;
      text-align: center;
    }
    h1 {
      color: #7ee081;
      font-size: 48px;
      margin: 10px;
    }
    canvas {
      border: 6px solid #3fa34d;
      border-radius: 10px;
    }
    #score, #best {
      color: yellow;
      font-weight: bold;
    }
    .help {
      color: #9fb8a5;
    }
  </style>
</head>
<body>
  <h1>Serpiente</h1>
  <p>Puntos: <span id="score">0</span> | Récord: <span id="best">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <p class="help">Flechas - mover, espacio - nueva partida</p>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake;
    let apple = { x: 0, y: 0 };
    let dx;
    let dy;
    let nextDx;
    let nextDy;
    let score;
    let gameOver;
    let timer;
    let speed;
    let best = Number(localStorage.getItem("snakeBest"));

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function drawApple() {
      ctx.fillStyle = "red";
      ctx.beginPath();
      ctx.arc(apple.x * size + size / 2, apple.y * size + size / 2, size / 2 - 1, 0, Math.PI * 2);
      ctx.fill();
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function isOnSnake(x, y) {
      for (let i = 0; i < snake.length; i++) {
        if (snake[i].x === x && snake[i].y === y) {
          return true;
        }
      }
      return false;
    }

    function showScore() {
      document.getElementById("score").textContent = score;
      document.getElementById("best").textContent = best;
    }

    function placeApple() {
      apple.x = randomCell();
      apple.y = randomCell();
      while (isOnSnake(apple.x, apple.y)) {
        apple.x = randomCell();
        apple.y = randomCell();
      }
    }

    function draw() {
      clearField();
      drawApple();
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function endGame() {
      gameOver = true;
      clearInterval(timer);
      if (score > best) {
        best = score;
        localStorage.setItem("snakeBest", best);
        showScore();
      }
      ctx.fillStyle = "white";
      ctx.font = "32px sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("Fin del juego", 200, 200);
      ctx.font = "18px sans-serif";
      ctx.fillText("Pulsa espacio para jugar otra vez", 200, 240);
    }

    function step() {
      dx = nextDx;
      dy = nextDy;
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
        endGame();
        return;
      }
      if (isOnSnake(head.x, head.y)) {
        endGame();
        return;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        showScore();
        placeApple();
        if (speed > 60) {
          speed = speed - 10;
          clearInterval(timer);
          timer = setInterval(step, speed);
        }
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        nextDx = 0;
        nextDy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        nextDx = 0;
        nextDy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        nextDx = -1;
        nextDy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        nextDx = 1;
        nextDy = 0;
      }
      if (event.key === " " && gameOver) {
        startGame();
      }
    }

    function startGame() {
      snake = [
        { x: 10, y: 10 },
        { x: 9, y: 10 },
        { x: 8, y: 10 }
      ];
      dx = 1;
      dy = 0;
      nextDx = 1;
      nextDy = 0;
      score = 0;
      gameOver = false;
      speed = 200;
      showScore();
      placeApple();
      draw();
      timer = setInterval(step, speed);
    }

    document.addEventListener("keydown", onKey);
    startGame();
  </script>
</body>
</html>
