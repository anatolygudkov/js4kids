Funciones

Escribir cada vez fillStyle y luego fillRect con cuatro números es aburrido. Vamos a inventar nuestra propia orden: «dibuja una casilla». Estas órdenes caseras se llaman funciones.

En esta lección vas a:
  • dividir el campo en casillas, como una hoja de cuadros;
  • escribir las funciones clearField y drawCell;
  • descubrir qué son los parámetros de una función;
  • dibujar la serpiente con números de casilla en lugar de píxeles.

Un campo hecho de casillas

La serpiente se mueve por casillas. Nuestro lienzo mide 400 por 400 píxeles. Si cada casilla mide 20 píxeles, en una fila caben 400 / 20 = 20 casillas. Las numeramos desde cero: de 0 a 19.

¿Ves la regla? Píxeles = número de casilla × 20. Que esa multiplicación la haga el ordenador.

La primera función

Una función es una receta: escribimos una vez qué hay que hacer y le ponemos un nombre a la receta. Después basta con decir el nombre y el ordenador hace todos los pasos. Empezamos con una receta sencilla, «limpia el campo»:

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}
  • function — «ahora viene una receta»;
  • clearField — su nombre (clear field significa «limpiar el campo»);
  • () — los paréntesis son obligatorios, aunque estén vacíos;
  • entre las llaves { } van los pasos de la receta. Se escriben con sangría para que se vea que están dentro.

Una receta escrita no hace nada por sí sola. Para que funcione, hay que llamarla: escribir su nombre con paréntesis:

clearField();

Ya conoces funciones que inventaron otras personas: alert(...), console.log(...), ctx.fillRect(...). ¡Ahora sabes hacer las tuyas!

Una función con parámetros

Para dibujar una casilla hay que saber dónde y de qué color. Esos datos se le pasan a la función entre paréntesis. Se llaman parámetros:

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

Cuando escribimos drawCell(3, 2, "lime"), la función recibe tres cajas: en x va un 3, en y un 2 y en color va "lime". Después multiplica los números de casilla por el tamaño size y dibuja.

💡 ¿Por qué size - 1? El cuadrado sale un píxel más pequeño que la casilla, y entre trozos vecinos queda una rendija finita. Así se ve de qué trozos está hecha la serpiente. Luego prueba a escribir solo size y compara.

Reescribimos el juego

Ahora cambia el script de snake.html: las líneas viejas con fillRect ya no hacen falta.

💡 Sobre la sangría A partir de ahora las lecciones muchas veces muestran solo el trozo de código que va dentro de <script>, sin la sangría de la izquierda. En tu archivo esas líneas están desplazadas a la derecha porque van dentro de la etiqueta <script>. Déjalas así: al ordenador las sangrías le dan igual, están para que las personas lean mejor el código. Cómo queda todo junto lo puedes ver siempre en el archivo completo al final de la lección. 
let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
let size = 20;

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

clearField();
drawCell(10, 10, "lime");
drawCell(9, 10, "lime");
drawCell(8, 10, "lime");
drawCell(15, 10, "red");

Guarda y recarga. Una serpiente de tres trozos mira a la derecha, y delante tiene una manzana. Fíjate qué fácil es ahora mover los trozos: cambias el número de casilla y listo.

⚠️ Errores frecuentes
  • Falta la llave de cierre }: sale el error missing } after function body, «falta una } después del cuerpo de la función».
  • Llamas a la función, pero su nombre está escrito distinto (drawcell en lugar de drawCell): sale el error drawcell is not defined.
🎯 Tareas
  1. Dibuja con casillas la primera letra de tu nombre.
  2. Pon una manzana en cada una de las cuatro esquinas del campo. ¿Qué números tienen las casillas de las esquinas? (Pista: la última casilla es la 19, no la 20.)
  3. Pon la cabeza de la serpiente de otro color, por ejemplo "yellow".
  4. ⭐ Escribe una función drawApple(x, y) que dibuje una casilla roja. ¡Por dentro puede limitarse a llamar a drawCell!
Cuando termines, deja la serpiente y la manzana como en el código de arriba: la próxima lección empieza desde ahí.
