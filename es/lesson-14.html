Velocidad y récord

El juego funciona, pero es demasiado tranquilo. Hoy la serpiente acelerará con cada manzana, el juego aprenderá a recordar tu récord incluso después de apagar el ordenador, y cazaremos un bug muy astuto.

En esta lección vas a:
  • hacer que la serpiente acelere;
  • guardar el récord en la memoria del navegador con localStorage;
  • encontrar y arreglar el bug de la media vuelta rápida.

1. La velocidad aumenta

Ahora el temporizador salta siempre cada 200 milisegundos. Vamos a guardar ese número en una variable llamada speed («velocidad» en inglés). En realidad es la pausa entre pasos: cuanto más pequeño es el número, más rápida va la serpiente.

Añade la variable arriba, con las demás:

let gameOver;
let timer;
let speed;

En startGame pon la velocidad inicial y úsala en el temporizador:

  gameOver = false;
  speed = 200;
  showScore();
  placeApple();
  draw();
  timer = setInterval(step, 200);
  timer = setInterval(step, speed);
}

Y cuando la serpiente se come una manzana, acortamos la pausa 10 milisegundos. A un temporizador no se le puede cambiar la velocidad sobre la marcha, así que apagamos el viejo y ponemos en marcha uno nuevo, más rápido:

  if (head.x === apple.x && head.y === apple.y) {
    score = score + 1;
    showScore();
    placeApple();
    if (speed > 60) {
      speed = speed - 10;
      clearInterval(timer);
      timer = setInterval(step, speed);
    }
  } else {
    snake.pop();
  }

La comprobación speed > 60 sirve para que el juego no llegue a una velocidad imposible: la serpiente nunca irá más rápido que 60 milisegundos por paso.

2. El récord

Cuando la página se recarga o se cierra, todas las variables desaparecen: el programa empieza de nuevo. ¡Pero el récord queremos recordarlo siempre! Para eso el navegador tiene su propia memoria pequeñita: localStorage («almacén local»). Es como una libreta donde puedes apuntar un valor con un nombre:

localStorage.setItem("snakeBest", 25);         // apuntar
localStorage.getItem("snakeBest");             // leer

Lo que apuntas en esta libreta se queda ahí aunque cierres el navegador y apagues el ordenador.

Un sitio para el récord en la página

<p>Puntos: <span id="score">0</span></p>
<p>Puntos: <span id="score">0</span> | Récord: <span id="best">0</span></p>

Leemos el récord al empezar

Añade una variable arriba:

let best = Number(localStorage.getItem("snakeBest"));

La libreta localStorage lo guarda todo como texto, pero nosotros necesitamos un número para comparar. Number(...) convierte un texto en número. Si todavía no hay récord, getItem devuelve null («nada»), y Number(null) es 0. ¡Justo lo que necesitamos!

Lo mostramos y lo guardamos

Que showScore muestre los dos números:

function showScore() {
  document.getElementById("score").textContent = score;
  document.getElementById("best").textContent = best;
}

Y en endGame, justo después de clearInterval(timer);, comprobamos si se ha batido el récord:

function endGame() {
  gameOver = true;
  clearInterval(timer);
  if (score > best) {
    best = score;
    localStorage.setItem("snakeBest", best);
    showScore();
  }
  ...

Juega, consigue unos cuantos puntos y pierde. Luego cierra la pestaña y vuelve a abrir el juego: ¡el récord sigue ahí! 🏆

💡 Cómo borrar el récord En la consola escribe localStorage.removeItem("snakeBest") y recarga la página.

3. A la caza del bug

Un bug («bicho» en inglés) es como se llama a un error en un programa. Haz un experimento: deja que la serpiente vaya a la derecha. Ahora, muy rápido, casi a la vez, pulsa ↑ y enseguida ←. ¡A veces la serpiente pierde sin motivo! ¿Por qué?

Vamos a verlo paso a paso. Entre dos pasos de la serpiente se han pulsado dos teclas:

  1. ↑: la serpiente va a la derecha, dy no vale 1, así que se puede girar. Ahora dx = 0, dy = -1. ¡Pero la serpiente todavía no se ha movido!
  2. ←: comprobamos dx !== 1. Ahora dx ya vale 0, así que se puede. Ahora dx = -1.
  3. Llega el paso: la serpiente, que en realidad iba hacia la derecha, da un paso hacia la izquierda, directo contra su cuello.

El arreglo: guardaremos la tecla pulsada como la dirección siguiente, y solo cambiaremos la dirección de verdad al principio de cada paso. Las comprobaciones se harán con la dirección de verdad.

Añade dos variables más arriba:

let dx;
let dy;
let nextDx;
let nextDy;

En startGame dales valores iniciales, al lado de dx y dy:

  dx = 1;
  dy = 0;
  nextDx = 1;
  nextDy = 0;

Al principio del todo de step aplicamos la dirección siguiente:

function step() {
  dx = nextDx;
  dy = nextDy;
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };

Y en onKey solo cambiamos nextDx y nextDy (las comprobaciones se quedan igual):

function onKey(event) {
  if (event.key === "ArrowUp" && dy !== 1) {
    nextDx = 0;
    nextDy = -1;
  }
  if (event.key === "ArrowDown" && dy !== -1) {
    nextDx = 0;
    nextDy = 1;
  }
  if (event.key === "ArrowLeft" && dx !== 1) {
    nextDx = -1;
    nextDy = 0;
  }
  if (event.key === "ArrowRight" && dx !== -1) {
    nextDx = 1;
    nextDy = 0;
  }
  if (event.key === " " && gameOver) {
    startGame();
  }
}

Ahora, en nuestro ejemplo, la segunda tecla ← se comprueba con la dirección de verdad: dx todavía vale 1 (la serpiente va a la derecha), así que girar a la izquierda está prohibido. ¡Bug cazado! 🐞

📄 El archivo snake.html completo después de esta lección 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <p>Puntos: <span id="score">0</span> | Récord: <span id="best">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake;
    let apple = { x: 0, y: 0 };
    let dx;
    let dy;
    let nextDx;
    let nextDy;
    let score;
    let gameOver;
    let timer;
    let speed;
    let best = Number(localStorage.getItem("snakeBest"));

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function isOnSnake(x, y) {
      for (let i = 0; i < snake.length; i++) {
        if (snake[i].x === x && snake[i].y === y) {
          return true;
        }
      }
      return false;
    }

    function showScore() {
      document.getElementById("score").textContent = score;
      document.getElementById("best").textContent = best;
    }

    function placeApple() {
      apple.x = randomCell();
      apple.y = randomCell();
      while (isOnSnake(apple.x, apple.y)) {
        apple.x = randomCell();
        apple.y = randomCell();
      }
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function endGame() {
      gameOver = true;
      clearInterval(timer);
      if (score > best) {
        best = score;
        localStorage.setItem("snakeBest", best);
        showScore();
      }
      ctx.fillStyle = "white";
      ctx.font = "32px sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("Fin del juego", 200, 200);
      ctx.font = "18px sans-serif";
      ctx.fillText("Pulsa espacio para jugar otra vez", 200, 240);
    }

    function step() {
      dx = nextDx;
      dy = nextDy;
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
        endGame();
        return;
      }
      if (isOnSnake(head.x, head.y)) {
        endGame();
        return;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        showScore();
        placeApple();
        if (speed > 60) {
          speed = speed - 10;
          clearInterval(timer);
          timer = setInterval(step, speed);
        }
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        nextDx = 0;
        nextDy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        nextDx = 0;
        nextDy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        nextDx = -1;
        nextDy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        nextDx = 1;
        nextDy = 0;
      }
      if (event.key === " " && gameOver) {
        startGame();
      }
    }

    function startGame() {
      snake = [
        { x: 10, y: 10 },
        { x: 9, y: 10 },
        { x: 8, y: 10 }
      ];
      dx = 1;
      dy = 0;
      nextDx = 1;
      nextDy = 0;
      score = 0;
      gameOver = false;
      speed = 200;
      showScore();
      placeApple();
      draw();
      timer = setInterval(step, speed);
    }

    document.addEventListener("keydown", onKey);
    startGame();
  </script>
</body>
</html>
