Fin del juego

En un juego de verdad se puede perder; si no, no tiene gracia. Nuestra serpiente perderá si choca con una pared o se muerde la cola. Y en el campo aparecerá el mensaje «Fin del juego».

En esta lección vas a:
  • cambiar los portales por paredes de verdad;
  • escribir una función isOnSnake que comprueba si una casilla está ocupada por la serpiente;
  • aprender a parar un temporizador (clearInterval) y una función (return);
  • escribir texto en el lienzo.
Plan de la lección
5 minLas reglas para perder
15 minParar el juego: endGame, clearInterval, texto en el lienzo
10 minParedes en lugar de portales

5 min¡A jugar!

Parar el temporizador

A la serpiente la mueve el temporizador setInterval. Para que el juego se pare hay que apagarlo, y para eso tenemos que guardarlo en una variable. Cambia la última línea del programa:

setInterval(step, 200);
let timer = setInterval(step, 200);

setInterval devuelve el número del temporizador, y lo guardamos en timer. El temporizador se apaga con la orden clearInterval(timer).

La función «Fin del juego»

Añade una función nueva después de draw:

function endGame() {
  clearInterval(timer);
  ctx.fillStyle = "white";
  ctx.font = "32px sans-serif";
  ctx.textAlign = "center";
  ctx.fillText("Fin del juego", 200, 200);
}
  • clearInterval(timer) — apagar el temporizador: step ya no se llama y la serpiente se queda quieta;
  • ctx.font — el tamaño y el tipo de letra: 32 píxeles, una letra sin remates (sans-serif);
  • ctx.textAlign = "center" — centrar el texto;
  • ctx.fillText(texto, x, y) — escribir un texto en el punto (x, y). El punto (200, 200) es el centro del campo.
💡 Pruébalo en la consola Escribe endGame() en la consola y pulsa Intro: la serpiente se para y aparece el mensaje. Así se pueden probar las funciones una por una, incluso antes de conectarlas al juego.

Paredes

Los portales eran divertidos, pero en la Serpiente clásica las paredes son peligrosas. Quita de step las cuatro comprobaciones de los portales y pon una sola comprobación de paredes:

function step() {
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };

  if (head.x >= cells) {
    head.x = 0;
  }
  if (head.x < 0) {
    head.x = cells - 1;
  }
  if (head.y >= cells) {
    head.y = 0;
  }
  if (head.y < 0) {
    head.y = cells - 1;
  }
  if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
    endGame();
    return;
  }

  snake.unshift(head);
  ...

Con || («o») hemos juntado cuatro preguntas en una: «¿la cabeza está a la izquierda del campo, o a la derecha, o por encima, o por debajo?». Si cualquiera de esas cosas es verdad, se acaba el juego.

¿Para qué sirve return?

return termina la función en el acto: las líneas de debajo ya no se ejecutan. Sin él, la serpiente, después de «chocar», añadiría igualmente una cabeza fuera del campo y volvería a dibujarlo todo encima del mensaje «Fin del juego».

Morderse la cola

Hay que comprobar si la cabeza nueva ha caído en una casilla donde ya hay un trozo de la serpiente. Para eso recorremos todos los trozos con un bucle y comparamos las coordenadas. Vamos a escribir una función-pregunta que contesta true o false:

function isOnSnake(x, y) {
  for (let i = 0; i < snake.length; i++) {
    if (snake[i].x === x && snake[i].y === y) {
      return true;
    }
  }
  return false;
}

Cómo funciona:

  • el bucle mira uno por uno todos los trozos de la serpiente;
  • si encuentra un trozo en la casilla (x, y), la función contesta enseguida true («sí, aquí está la serpiente») y termina;
  • si el bucle lo ha revisado todo y no ha encontrado nada, el programa llega a la última línea y contesta false.

El nombre de la función suena a pregunta: is on snake?, «¿está en la serpiente?». Así se suelen llamar las funciones que contestan «sí» o «no».

Ahora la usamos en step, justo después de comprobar las paredes:

  if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
    endGame();
    return;
  }
  if (isOnSnake(head.x, head.y)) {
    endGame();
    return;
  }

Guarda, recarga y prueba las dos maneras de perder: choca con una pared y luego haz crecer la serpiente y muérdete. Para volver a jugar, de momento pulsa F5. En la próxima lección haremos que se reinicie con la barra espaciadora.

  2. Pon el mensaje en rojo o en amarillo.
  3. ⭐ Antes del mensaje, dibuja un rectángulo semitransparente para que el texto se lea mejor. Un color con transparencia se escribe así: "rgba(0, 0, 0, 0.6)", negro con un 40 % de transparencia.
📄 El archivo snake.html completo después de esta lección 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <p>Puntos: <span id="score">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;
    let score = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function isOnSnake(x, y) {
      for (let i = 0; i < snake.length; i++) {
        if (snake[i].x === x && snake[i].y === y) {
          return true;
        }
      }
      return false;
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function endGame() {
      clearInterval(timer);
      ctx.fillStyle = "white";
      ctx.font = "32px sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("Fin del juego", 200, 200);
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
        endGame();
        return;
      }
      if (isOnSnake(head.x, head.y)) {
        endGame();
        return;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        document.getElementById("score").textContent = score;
        apple.x = randomCell();
        apple.y = randomCell();
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        dx = 0;
        dy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        dx = 0;
        dy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        dx = -1;
        dy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        dx = 1;
        dy = 0;
      }
    }

    document.addEventListener("keydown", onKey);
    draw();
    let timer = setInterval(step, 200);
  </script>
</body>
</html>
