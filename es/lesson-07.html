Arrays y objetos

Ahora mismo la serpiente se dibuja con tres órdenes sueltas. Pero va a moverse y a crecer, y el ordenador tiene que recordar dónde está cada uno de sus trozos. Para eso existen los objetos y los arrays.

En esta lección vas a:
  • describir la manzana con un objeto { x: 15, y: 10 };
  • describir la serpiente con un array: una lista de trozos;
  • dibujar la serpiente entera con un bucle;
  • escribir una función draw que dibuja todo el juego.

Un objeto es una caja con compartimentos

La manzana tiene dos números: x e y. Podrías hacer dos variables, appleX y appleY, pero es más cómodo meterlos en una sola caja con compartimentos. Una caja así se llama objeto:

let apple = { x: 15, y: 10 };

Un objeto se escribe entre llaves. Dentro van sus propiedades: nombre, dos puntos, valor. Las propiedades se separan con comas. Para sacar un valor se usa un punto:

console.log(apple.x);   // 15
console.log(apple.y);   // 10
apple.x = 3;            // hemos movido la manzana

Ya has visto antes un punto así: ctx.fillStyle, console.log. ¡También son objetos con propiedades!

Un array es una lista

Un array es una lista donde los valores van en orden. Se escribe entre corchetes:

let colors = ["red", "green", "blue"];
console.log(colors[0]);       // red
console.log(colors[2]);       // blue
console.log(colors.length);   // 3
  • Cada sitio de la lista tiene un número. Se llama índice.
  • ¡Los números empiezan desde cero! El primer elemento es colors[0], el segundo es colors[1].
  • colors.length es la longitud de la lista: cuántos elementos tiene.
⚠️ El último elemento Si una lista tiene 3 elementos, sus números son 0, 1, 2. No existe el elemento número 3: colors[3] devuelve undefined («sin definir»). El último elemento siempre tiene el número length - 1.

La serpiente es una lista de trozos

Cada trozo de la serpiente es una casilla con coordenadas x e y, es decir, un objeto. Y la serpiente entera es una lista de esos objetos. El primero de la lista (el número 0) siempre será la cabeza:

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];

¿Cómo se sacan las coordenadas de la cabeza? Primero cogemos el elemento de la lista y luego su propiedad: snake[0].x es 10, snake[2].x es 8.

Dibujamos toda la serpiente con un bucle

El bucle recorre todos los trozos con números del 0 al snake.length - 1 y dibuja cada uno:

for (let i = 0; i < snake.length; i++) {
  drawCell(snake[i].x, snake[i].y, "lime");
}

Tenga la serpiente los trozos que tenga, 3 o 300, este bucle los dibuja todos.

La función draw

Vamos a juntar todo el dibujo en una función, draw («dibujar»): limpiar el campo, dibujar la manzana y la serpiente. La cabeza la dibujaremos en amarillo encima del trozo verde, para que se vea hacia dónde mira la serpiente. Cambia el script así (lo nuevo está en verde y lo que hay que borrar, en rojo):

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
let size = 20;
let cells = 20;

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];
let apple = { x: 15, y: 10 };

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

function draw() {
  clearField();
  drawCell(apple.x, apple.y, "red");
  for (let i = 0; i < snake.length; i++) {
    drawCell(snake[i].x, snake[i].y, "lime");
  }
  drawCell(snake[0].x, snake[0].y, "yellow");
}

clearField();
drawCell(10, 10, "lime");
drawCell(9, 10, "lime");
drawCell(8, 10, "lime");
drawCell(15, 10, "red");
draw();
💡 El orden del programa Arriba, las variables (lo que recordamos); en medio, las funciones (lo que sabemos hacer); abajo, las llamadas (lo que hacemos ahora mismo). Este orden ayuda a no perderse cuando el programa se hace largo.

Un truco con la consola

¡Las variables del programa se pueden cambiar directamente desde la consola! Ábrela (F12) y escribe una por una, pulsando Intro después de cada línea:

snake.push({ x: 7, y: 10 });
draw();

¡La serpiente se ha alargado! La orden push añade un elemento nuevo al final de la lista. Prueba más:

snake.length
apple.x = 2;
draw();

Si recargas la página (F5), todo vuelve a estar como antes: el programa empieza otra vez desde el principio.
