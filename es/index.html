Programamos el juego de la Serpiente en JavaScript

¡Hola! En este curso vas a escribir, línea a línea, un juego de ordenador de verdad: la Serpiente. Podrás enseñárselo a tus amigos e incluso publicarlo en internet.

Qué necesitas:
  • un ordenador Raspberry Pi con Raspberry Pi OS, un monitor, un teclado y un ratón;
  • el editor Geany (en la lección 0 verás cómo encontrarlo o instalarlo);
  • el navegador Firefox (viene con Raspberry Pi OS);
  • curiosidad, paciencia y un poco de valor para equivocarte. ¡Equivocarse es normal!
👨‍👩‍👧 Para personas adultas

El curso está pensado para una niña o un niño de unos 10 años que nunca ha programado y todavía no conoce Linux ni los editores de código. No hace falta la terminal: todo se hace con el ratón, en el editor y en el navegador. Todos los archivos están en una sola carpeta, y el juego es un único archivo, snake.html. Los estilos (CSS) se dejan a propósito para cuando el juego está terminado: primero aprendemos a programar y después decoramos. Todo funciona en local, sin git ni internet; internet solo hace falta en la última lección, donde el juego se publica en GitHub Pages a través de la web.

  • Una sesión, una lección: 40–60 minutos. Cada lección empieza con un plan minuto a minuto. Si hay cansancio, es mejor parar a mitad y seguir otro día.
  • El código se escribe a mano, no se copia. Así se memorizan tanto las órdenes como los símbolos del teclado. Las erratas y buscarlas también forman parte del aprendizaje.
  • No deis la solución enseguida. Primero preguntad: «¿Qué dice la consola? ¿Qué línea?». Aprender a encontrar errores es tan importante como escribir código.
  • Las tareas con estrella ⭐ son opcionales, para quien quiera más.
