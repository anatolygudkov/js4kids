La serpiente se mueve

Unos dibujos animados son muchas imágenes que se cambian muy deprisa. Nuestro juego funcionará igual: varias veces por segundo moverá la serpiente y dibujará una imagen nueva. ¡Hoy la serpiente cobra vida!

En esta lección vas a:
  • aprender un truco para mover la serpiente: cabeza delante, cola fuera;
  • conocer las órdenes de los arrays unshift y pop;
  • poner en marcha el temporizador setInterval;
  • aprender a indicar la dirección con las variables dx y dy.

Cómo se mueve una serpiente

Podrías mover cada trozo de la serpiente uno por uno, pero hay una forma más sencilla. Mira: para que la serpiente avance una casilla, basta con:

  1. añadir una cabeza nueva en la casilla de delante;
  2. quitar el último trozo de la cola.

Los arrays tienen órdenes ya preparadas para esto:

  • snake.unshift(algo) — añadir un elemento al principio de la lista (en el sitio número 0);
  • snake.pop() — quitar el último elemento de la lista.
💡 Pruébalo en la consola Abre snake.html, pulsa F12 y escribe una por una: 
snake.unshift({ x: 11, y: 10 });
snake.pop();
draw();
¡La serpiente ha avanzado una casilla a la derecha! Repite estas tres líneas un par de veces más (la flecha ↑ en la consola recupera las órdenes anteriores).

Hacia dónde ir: dx y dy

La cabeza nueva aparece al lado de la vieja. Dónde exactamente, depende de la dirección. Vamos a crear dos variables:

  • dx — cuántas casillas moverse en x en cada paso;
  • dy — cuántas casillas moverse en y.
Direccióndxdy
derecha →10
izquierda ←-10
abajo ↓01
arriba ↑0-1

(¿Recuerdas que en la pantalla y crece hacia abajo? Por eso «arriba» es -1.)

Entonces la cabeza nueva es la cabeza vieja más el desplazamiento:

let head = { x: snake[0].x + dx, y: snake[0].y + dy };

Un paso del juego

Lo juntamos todo en una función, step («paso»): crear la cabeza nueva, añadirla, quitar la cola, volver a dibujar.

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];
let apple = { x: 15, y: 10 };
let dx = 1;
let dy = 0;

function clearField() { ... }      // sin cambios

function drawCell(x, y, color) { ... }   // sin cambios

function draw() { ... }            // sin cambios

function step() {
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };
  snake.unshift(head);
  snake.pop();
  draw();
}

draw();
setInterval(step, 200);
⚠️ ¡No escribas los puntos suspensivos! { ... } // sin cambios significa que la función se queda igual que estaba. ¡No la borres! Si tienes dudas, mira el archivo completo al final de la lección.

Guarda, recarga… ¡La serpiente se mueve! 🎉

El temporizador

setInterval(step, 200);

setInterval significa «llama a la función step una y otra vez, cada 200 milisegundos». Un milisegundo es la milésima parte de un segundo, así que 200 milisegundos son la quinta parte de un segundo. Por tanto, la serpiente da 5 pasos por segundo.

⚠️ ¡Sin paréntesis! Se escribe setInterval(step, 200), no setInterval(step(), 200). No llamamos a step nosotros: se la entregamos al temporizador para que la llame él cuando toque.

Y luego la serpiente se sale por el borde del campo y desaparece… No se ha esfumado: sus coordenadas se han hecho mayores que 19 y se mueve por algún sitio fuera del lienzo. Lo arreglaremos en la próxima lección.

🎯 Experimentos
  1. Cambia 200 por 500 y luego por 50. ¿Cómo cambia la velocidad?
  2. Haz que la serpiente vaya hacia abajo. ¿Qué dx y dy hacen falta?
  3. Haz que la serpiente vaya a la izquierda. Fíjate bien en lo que pasa justo al principio. ¿Por qué?
  4. ¿Qué pasa si dx = 1 y dy = 1 a la vez?
  5. ⭐ Convierte en comentario la línea snake.pop(); (ponle // delante). ¿Qué le pasa a la serpiente? ¡Acuérdate de esto, te servirá cuando la serpiente coma manzanas!
Al final deja dx = 1, dy = 0, la velocidad en 200 y la línea snake.pop(); sin comentario.
📄 El archivo snake.html completo después de esta lección 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };
      snake.unshift(head);
      snake.pop();
      draw();
    }

    draw();
    setInterval(step, 200);
  </script>
</body>
</html>

  • Sé qué hacen unshift y pop.
  • Entiendo que setInterval(step, 200) llama a step 5 veces por segundo.
