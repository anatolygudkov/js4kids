    } else {
      ctx.fillStyle = "black";

P3 Proyecto ⭐⭐⭐ 

    
Manzana dorada: a veces (1 de cada 5) aparece una manzana dorada que vale 5 puntos.

    
Este ejercicio resuélvelo en tu propio archivo en Geany: aquí no se puede ejecutar.

    
💡 Pista
Añade al objeto apple una propiedad gold. Dale valor en placeApple y úsala en draw y en step.

    
✅ Ver la respuesta
Math.random() < 0.2 es verdad más o menos el 20 % de las veces, 1 de cada 5. Una comparación ya da true o false, así que se puede guardar directamente en la propiedad.
// al final de placeApple()
apple.gold = Math.random() < 0.2;

// en draw(), en lugar de drawApple()
if (apple.gold) {
  drawCell(apple.x, apple.y, "gold");
} else {
  drawApple();
}

// en step(), cuando la serpiente se ha comido la manzana
if (apple.gold) {
  score = score + 5;
} else {
  score = score + 1;
}
