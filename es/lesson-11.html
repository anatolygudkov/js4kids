La manzana y el crecimiento

La serpiente atraviesa la manzana y ni se entera. ¡Vamos a enseñarle a comer! Se come una manzana: crece un trozo, gana un punto, y aparece una manzana nueva en un sitio al azar.

En esta lección vas a:
  • obtener números al azar con Math.random y Math.floor;
  • escribir una función que devuelve una respuesta (return);
  • enseñar a la serpiente a comer y a crecer;
  • mostrar los puntos en la página.

Números al azar

Abre la consola y escribe varias veces:

Math.random()

Cada vez sale un número decimal nuevo entre 0 y 1 (pero nunca exactamente 1): 0.7364…, 0.0912…. Math es un conjunto de órdenes matemáticas que trae JavaScript, y random significa «al azar».

Pero nosotros necesitamos una casilla del 0 al 19. Lo haremos en dos pasos:

  1. Math.random() * 20 — un número al azar entre 0 y 19,999…;
  2. Math.floor(...) — quitar la parte decimal (floor significa «suelo»: redondear hacia abajo). De 13.82 sale 13.
Math.floor(Math.random() * 20)

Repítelo muchas veces en la consola: saldrán números enteros del 0 al 19, como en un dado de veinte caras.

Una función que responde

Hasta ahora nuestras funciones hacían algo: dibujaban, movían. Pero también hay funciones que responden: devuelven un resultado. Para eso existe la palabra return («devolver»):

function randomCell() {
  return Math.floor(Math.random() * cells);
}

Ahora puedes escribir randomCell() donde necesites un número al azar: apple.x = randomCell();, y en apple.x entrará la respuesta de la función. Igual que prompt devolvía lo que había escrito la persona.

La serpiente come

¿Cómo sabemos que la serpiente se ha comido la manzana? Su cabeza nueva está en la misma casilla que la manzana: coinciden la x y la y.

if (head.x === apple.x && head.y === apple.y) {

Y ahora el truco. ¿Te acuerdas del experimento de la lección 8, cuando quitamos snake.pop() y la serpiente crecía? Haremos justo eso: si la serpiente se ha comido la manzana, no quitamos la cola. La cabeza se ha añadido, la cola se ha quedado, ¡y la serpiente es un trozo más larga!

Cambiamos el programa

1. En el HTML, entre el título y el lienzo, añade una línea con los puntos:

<h1>Serpiente</h1>
<p>Puntos: <span id="score">0</span></p>
<canvas id="game" width="400" height="400"></canvas>

<p> es un párrafo, y <span> es un trocito de texto dentro de él. Le hemos dado el nombre id="score" para encontrarlo desde JavaScript y cambiar el número.

2. Añade una variable para los puntos después de dx y dy:

let dx = 1;
let dy = 0;
let score = 0;

3. Añade la función randomCell después de drawCell:

function randomCell() {
  return Math.floor(Math.random() * cells);
}

4. En la función step, cambia la línea snake.pop(); por una comprobación:

  snake.unshift(head);
  snake.pop();

  if (head.x === apple.x && head.y === apple.y) {
    score = score + 1;
    document.getElementById("score").textContent = score;
    apple.x = randomCell();
    apple.y = randomCell();
  } else {
    snake.pop();
  }

  draw();
}

Leámoslo en español: «Si la cabeza está en la manzana, sumar un punto, mostrarlo en la página y llevar la manzana a un sitio al azar. Si no, quitar la cola».

document.getElementById("score") encuentra nuestro <span> en la página, y .textContent = score cambia el texto de dentro por el número nuevo.

Guarda, recarga ¡e intenta atrapar la manzana! 🍎

📄 El archivo snake.html completo después de esta lección 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <p>Puntos: <span id="score">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;
    let score = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x >= cells) {
        head.x = 0;
      }
      if (head.x < 0) {
        head.x = cells - 1;
      }
      if (head.y >= cells) {
        head.y = 0;
      }
      if (head.y < 0) {
        head.y = cells - 1;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        document.getElementById("score").textContent = score;
        apple.x = randomCell();
        apple.y = randomCell();
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        dx = 0;
        dy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        dx = 0;
        dy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        dx = -1;
        dy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        dx = 1;
        dy = 0;
      }
    }

    document.addEventListener("keydown", onKey);
    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
