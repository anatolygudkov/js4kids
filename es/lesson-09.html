Condiciones

La serpiente se sale por el borde del campo. Necesitamos que el programa sepa decidir: si la serpiente está en el borde, entonces hacer algo especial. Para eso está la orden if. Con ella haremos portales mágicos: la serpiente entra por una pared y sale por la de enfrente.

En esta lección vas a:
  • descubrir qué son true y false;
  • aprender a comparar números: >, <, === y otros;
  • escribir condiciones if e if … else;
  • unir condiciones con «y» (&&) y «o» (||);
  • hacer portales en los bordes del campo.

¿Verdadero o falso?

Abre la consola y hazle preguntas al ordenador:

5 > 3
2 > 7
10 === 10
10 === 11

A cada pregunta el ordenador contesta true (verdadero) o false (falso). Estas son todas las formas de comparar:

SignoPreguntaEjemplo
>¿mayor?5 > 3 → true
<¿menor?5 < 3 → false
>=¿mayor o igual?20 >= 20 → true
<=¿menor o igual?0 <= -1 → false
===¿igual?7 === 7 → true
!==¿distinto?7 !== 7 → false
⚠️ ¿Uno, dos o tres signos igual? = (uno) significa «mete en la caja». === (tres) pregunta «¿son iguales?». ¡No los confundas! En este curso, para comparar siempre usamos tres signos igual.

Si… entonces… si no

let score = 12;

if (score > 10) {
  console.log("¡Muy bien!");
}

Entre los paréntesis que van después de if («si») va una pregunta. Si la respuesta es true, se ejecuta lo que hay entre las llaves. Si es false, se salta.

Y con else («si no») puedes decir qué hacer cuando la respuesta es «no»:

if (score > 10) {
  console.log("¡Muy bien!");
} else {
  console.log("¡Inténtalo otra vez!");
}

Cambia score a 5 y comprueba qué sale. Puedes hacer experimentos en prueba.html.

Portales mágicos

El campo va de la casilla 0 a la casilla 19. La cabeza de la serpiente se ha salido del campo si:

  • head.x >= cells — se ha salido por la derecha (x vale 20);
  • head.x < 0 — se ha salido por la izquierda (x vale -1);
  • head.y >= cells — se ha salido por abajo;
  • head.y < 0 — se ha salido por arriba.

En cada caso llevaremos la cabeza a la pared de enfrente. Añade las comprobaciones a la función step: después de crear head, pero antes de unshift.

function step() {
  let head = { x: snake[0].x + dx, y: snake[0].y + dy };

  if (head.x >= cells) {
    head.x = 0;
  }
  if (head.x < 0) {
    head.x = cells - 1;
  }
  if (head.y >= cells) {
    head.y = 0;
  }
  if (head.y < 0) {
    head.y = cells - 1;
  }

  snake.unshift(head);
  snake.pop();
  draw();
}

Guarda, recarga y mira: la serpiente llega al borde derecho y sale por la izquierda. ¡Los portales funcionan!

Cambia dx y dy al principio del programa para probar los cuatro portales.

💡 ¿Por qué cells - 1? cells vale 20, pero la última casilla es la número 19. Por eso, al salir por la pared izquierda, vamos a la casilla cells - 1, es decir, la 19.

«Y» y «o»

A veces hay que comprobar dos condiciones a la vez:

  • && — «y»: es verdad solo si las dos condiciones son verdad.
  • || — «o»: es verdad si al menos una condición es verdad.
let x = 5;
console.log(x > 0 && x < 10);    // true: x es mayor que 0 Y menor que 10
console.log(x < 0 || x > 3);     // true: al menos una se cumple
console.log(x < 0 || x > 100);   // false: no se cumple ninguna

El símbolo & es Mayús + 6, y | es AltGr + 1. Los dos se escriben dos veces. El «y» y el «o» nos harán falta ya en la próxima lección.

📄 El archivo snake.html completo después de esta lección 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x >= cells) {
        head.x = 0;
      }
      if (head.x < 0) {
        head.x = cells - 1;
      }
      if (head.y >= cells) {
        head.y = 0;
      }
      if (head.y < 0) {
        head.y = cells - 1;
      }

      snake.unshift(head);
      snake.pop();
      draw();
    }

    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
