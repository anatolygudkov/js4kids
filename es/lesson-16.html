El juego en internet

Hasta ahora el juego solo vivía en la carpeta codigo de tu Raspberry Pi. Hoy lo vamos a publicar en internet, y cualquiera con el enlace podrá jugar: amigos, abuelos, compañeros de clase. Nos ayudará un servicio gratuito llamado GitHub Pages.

En esta lección vas a:
  • preparar un archivo index.html para publicarlo;
  • crear un repositorio en la web de GitHub junto con una persona adulta;
  • subir allí el juego y activar GitHub Pages;
  • conseguir un enlace a tu juego;
  • pensar cómo mejorar el juego a partir de ahora.

👨‍👩‍👧 Para personas adultas

Las normas de GitHub solo permiten tener cuenta propia a partir de los 13 años. Por eso, usad la cuenta de una persona adulta (la vuestra o una creada para esto con vuestro correo) y haced la lección juntos. Hace falta conexión a internet.

No hace falta git ni la terminal: el archivo se sube desde la web con un botón. La web de GitHub está en inglés, así que abajo, junto a cada botón, va la traducción. Si la interfaz de GitHub ha cambiado un poco, buscad botones con los mismos nombres.

El juego publicado lo podrá ver todo el mundo. Comprobad que no contiene datos personales: apellidos, dirección, colegio.

Qué es GitHub

GitHub es una web donde programadoras y programadores de todo el mundo guardan sus programas. Cada programa vive en su propio repositorio (en inglés, repository o «repo»). Es como una carpeta en internet.

GitHub Pages es un servicio de GitHub que convierte un repositorio en una web de verdad con su propio enlace. Nuestro juego es una página HTML, ¡así que encaja perfectamente!

Paso 1. Preparamos el archivo

Cuando se abre una web por su enlace, lo primero que busca es una página llamada index.html (la «página principal»). Vamos a hacer una copia del juego con ese nombre:

  1. Abre snake.html en Geany.
  2. Archivo → Guardar como (Ctrl + Mayús + S), carpeta codigo, nombre index.html. Pulsa Guardar.
  3. Ahora Geany tiene abierto index.html. Cierra esa pestaña: tu juego lo seguirás cambiando en snake.html, e index.html es solo la copia para internet.

Mira en el gestor de archivos: en la carpeta codigo ahora hay tres archivos: prueba.html, snake.html e index.html.

Paso 2. Creamos un repositorio

  1. Abre en el navegador la web github.com e inicia sesión (Sign in). Esto lo hace una persona adulta.
  2. En la esquina de arriba a la derecha pulsa + y elige New repository («repositorio nuevo»).
  3. En el campo Repository name («nombre del repositorio») escribe snake.
  4. Comprueba que está elegido Public («público»): GitHub Pages funciona gratis con los repositorios públicos.
  5. Pulsa el botón verde Create repository («crear repositorio»).

Paso 3. Subimos el juego

  1. En la página del repositorio nuevo y vacío, busca el enlace uploading an existing file («subir un archivo que ya existe») y pulsa en él. (Si el repositorio no está vacío: el botón Add file → Upload files.)
  2. Pulsa choose your files («elige tus archivos»), abre tu carpeta personal → codigo y elige index.html. También puedes arrastrar el archivo con el ratón desde el gestor de archivos hasta la ventana del navegador.
  3. Abajo de la página pulsa el botón verde Commit changes («guardar los cambios»).

Ahora en la lista de archivos del repositorio se ve index.html. ¡Tu código ya está en internet!

Paso 4. Activamos GitHub Pages

  1. Arriba de la página del repositorio pulsa la pestaña Settings («ajustes», el icono del engranaje).
  2. En el menú de la izquierda busca y pulsa Pages.
  3. En el apartado Build and deployment («construcción y publicación»), en el campo Source («origen»), elige Deploy from a branch («publicar desde una rama»).
  4. En el campo Branch («rama») elige main y deja al lado la carpeta / (root). Pulsa Save («guardar»).
  5. Espera un par de minutos y recarga la página (F5). Arriba aparecerá el mensaje Your site is live at… («Tu web está publicada en…») y el botón Visit site («ver la web»).

La dirección será así:

https://NOMBRE-DE-LA-CUENTA.github.io/snake/

Pulsa Visit site y ahí está: ¡tu Serpiente en internet! 🎉🐍 Copia el enlace de la barra de direcciones y mándaselo a tus amigos.

💡 El récord en internet El juego en internet tiene su propio récord, distinto del de la carpeta codigo. Y cada persona que juega tiene el suyo en su ordenador: localStorage vive en el navegador donde se juega.

Cómo actualizar el juego

Si mejoras algo del juego:

  1. Cambia y prueba snake.html como siempre.
  2. Vuelve a guardarlo como index.html con «Guardar como». Geany preguntará si quieres sustituir el archivo: di que sí. Cierra la pestaña de index.html.
  3. En GitHub, en el repositorio snake: Add file → Upload files, elige el index.html nuevo y pulsa Commit changes. El archivo viejo se sustituye por el nuevo.
  4. Espera uno o dos minutos y recarga la página del juego.
⚠️ Si no funciona
  • ¿Sale la página 404 (no encontrada)? Espera un par de minutos más: GitHub Pages no se activa al instante. Comprueba que el archivo se llama exactamente index.html, en minúsculas.
  • ¿En lugar del juego sale una lista de archivos o el texto del código? Comprueba que en los ajustes de Pages están elegidas la rama main y la carpeta / (root).
  • ¿El juego se abre pero no funciona? Abre la consola (F12): ¡ya sabes leer los errores!

Extra: jugar en el móvil

El enlace también se puede abrir en un móvil, pero ahí no hay teclado con flechas. ¡Vamos a poner botones en la pantalla! Aquí hay un truco: a la función onKey solo le hace falta event.key, así que un botón puede llamarla él mismo y «hacerse pasar» por una tecla.

Añade en snake.html, debajo de la pista <p class="help">:

<p>
  <button onclick="onKey({ key: 'ArrowUp' })">Arriba</button>
</p>
<p>
  <button onclick="onKey({ key: 'ArrowLeft' })">Izquierda</button>
  <button onclick="onKey({ key: ' ' })">Empezar</button>
  <button onclick="onKey({ key: 'ArrowRight' })">Derecha</button>
</p>
<p>
  <button onclick="onKey({ key: 'ArrowDown' })">Abajo</button>
</p>
  • <button> — un botón;
  • onclick — qué hacer al pulsar el botón (también es un evento, como keydown);
  • { key: 'ArrowUp' } — hemos hecho nosotros un objeto que se parece a un evento de verdad. Dentro de las comillas dobles, el texto va entre comillas simples '…', para que no se mezclen las comillas.

Y un poco de CSS en <style>, para que los botones se pulsen bien con el dedo y el campo quepa en una pantalla estrecha:

    button {
      font-size: 20px;
      width: 110px;
      height: 56px;
      margin: 4px;
    }
    canvas {
      max-width: 90%;
    }

Comprueba en el ordenador que los botones funcionan, después actualiza index.html en GitHub y abre el enlace en un móvil.
