Bucles

¿Cómo se dibuja una fila de 20 casillas? Puedes escribir 20 líneas con drawCell… O solo una, si le pides al ordenador que repita. Una repetición en programación se llama bucle.

En esta lección vas a:
  • conocer el bucle for y sus partes;
  • seguir paso a paso cómo funciona un bucle;
  • dibujar filas, columnas y diagonales de casillas.

Contamos hasta cinco

Añade estas líneas al final del script de snake.html:

for (let i = 0; i < 5; i++) {
  console.log("Paso número " + i);
}

Abre la consola (F12) y recarga la página:

Una sola línea dentro del bucle se ejecutó 5 veces, y cada vez la variable i tenía un número nuevo.

De qué está hecho el bucle for

Entre los paréntesis que van después de for hay tres partes, separadas por punto y coma:

ParteQué significa
let i = 0Inicio: creamos un contador i y le metemos un 0.
i < 5Condición: repetimos mientras i sea menor que 5.
i++Paso: después de cada vuelta, sumamos uno a i (es lo mismo que i = i + 1).

Y entre las llaves { } está el cuerpo del bucle: lo que hay que repetir.

Sigamos cómo ejecuta el ordenador el bucle:

  1. i = 0. ¿Es verdad que 0 < 5? Sí → ejecutamos el cuerpo → i++, ahora i = 1.
  2. ¿1 < 5? Sí → cuerpo → i = 2.
  3. … lo mismo con 2, 3 y 4 …
  4. i = 5. ¿5 < 5? No → el bucle termina y seguimos con el programa.
💡 ¿Por qué i? Es una tradición: i es la primera letra de la palabra índice. Puedes llamar al contador como quieras, pero i lo entiende cualquier programador.

Dibujamos con un bucle

Cambia el bucle de console.log por este:

for (let i = 0; i < 20; i++) {
  drawCell(i, 0, "gray");
}

¡En el borde de arriba ha aparecido una fila gris de 20 casillas! En cada vuelta i crece, y la siguiente casilla se dibuja más a la derecha: (0, 0), (1, 0), (2, 0)… (19, 0).

El número 20 es la cantidad de casillas de una fila, y lo vamos a necesitar muchas veces. Vamos a guardarlo en una variable. Añádela justo debajo de let size = 20;:

let cells = 20;

Ahora en el bucle puedes escribir i < cells. Si algún día quieres un campo más grande, solo tendrás que cambiar un número.

Pruébalo tú

Cambia la línea de dentro del bucle y mira qué sale:

Dentro del bucleQué se dibuja
drawCell(i, 0, "gray");una fila arriba
drawCell(i, 19, "gray");una fila abajo
drawCell(0, i, "gray");una columna a la izquierda
drawCell(i, i, "yellow");una diagonal de esquina a esquina

Dentro de un bucle se pueden escribir varias órdenes. Por ejemplo, este bucle dibuja un marco alrededor de todo el campo:

for (let i = 0; i < cells; i++) {
  drawCell(i, 0, "gray");
  drawCell(i, 19, "gray");
  drawCell(0, i, "gray");
  drawCell(19, i, "gray");
}
⚠️ Un bucle infinito Si la condición siempre es verdad (por ejemplo, si olvidas i++), el bucle nunca termina y la página se «cuelga». No pasa nada: cierra la pestaña del navegador, corrige el código y vuelve a abrir el archivo.

Limpieza

Eso eran experimentos. Antes de la próxima lección borra todos los bucles que dibujan en el campo, pero deja la variable cells. Debe quedar así:

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Serpiente</title>
</head>
<body>
  <h1>Serpiente</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    clearField();
    drawCell(10, 10, "lime");
    drawCell(9, 10, "lime");
    drawCell(8, 10, "lime");
    drawCell(15, 10, "red");
  </script>
</body>
</html>
