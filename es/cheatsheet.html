JavaScript

Mostrar cosas

alert("Ventanita con un mensaje");
console.log("Mensaje en la consola");
let name = prompt("¿Pregunta?");   // la respuesta va a name

Variables y operaciones

let score = 0;              // crear una caja
score = score + 1;          // cambiarla (¡sin let!)
score++;                    // lo mismo, más corto
let text = "Puntos: " + score; // pegar texto
// + - * /  — sumar, restar, multiplicar, dividir

Condiciones

if (score > 10) {
  // si es verdad
} else {
  // si no
}
// comparaciones: >  <  >=  <=  ===  !==
// y: &&     o: ||     no: !

Bucles

for (let i = 0; i < 10; i++) {
  // se repite 10 veces, i = 0, 1, … 9
}

while (condición) {
  // se repite mientras la condición sea verdad
}

Objetos y arrays

let apple = { x: 15, y: 10 };    // objeto
apple.x = 3;

let snake = [{ x: 1, y: 1 }, { x: 0, y: 1 }];  // array
snake[0]          // primer elemento (¡los números empiezan en cero!)
snake.length      // cuántos elementos hay
snake.push(a)     // añadir al final
snake.unshift(a)  // añadir al principio
snake.pop()       // quitar el último

Lienzo

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
ctx.fillStyle = "red";                 // color
ctx.fillRect(x, y, width, height);     // rectángulo
ctx.font = "32px sans-serif";          // tipo de letra
ctx.fillText("Texto", x, y);           // texto

(0, 0) es la esquina de arriba a la izquierda. x crece hacia la derecha; y, hacia abajo.
