Preparamos el ordenador

Antes de escribir un juego, vamos a preparar el sitio de trabajo: veremos cómo funciona el escritorio, buscaremos dónde se esconden las llaves y los corchetes en el teclado, crearemos una carpeta para nuestros programas y configuraremos un editor de código.

En esta lección vas a:
  • conocer el escritorio de Raspberry Pi OS;
  • encontrar los símbolos «de programador» en el teclado;
  • crear una carpeta llamada codigo para tus programas;
  • abrir y configurar el editor Geany;
  • colocar las ventanas del editor y del navegador para trabajar con comodidad.

👨‍👩‍👧 Para personas adultas: antes de la primera lección

Hace falta Raspberry Pi OS con escritorio (with desktop). Si todavía no está instalado, grabadlo en una tarjeta de memoria con Raspberry Pi Imager, que se descarga de raspberrypi.com. Es cómodo crear desde el principio un usuario propio para la niña o el niño.

Comprobad que la distribución del teclado del sistema coincide con el teclado físico, por ejemplo Español (España) o Español (Latinoamérica). Se configura en Menú → Preferencias → Control Centre / Configuración de Raspberry Pi, en el apartado de teclado o localización (los nombres cambian un poco según la versión del sistema).

Es mejor hacer esta lección juntos.

1. El escritorio

Enciende la Raspberry Pi y espera a que aparezca el escritorio: una pantalla con una imagen y una barra arriba. Esa barra se llama barra de tareas.

  • En la esquina izquierda de la barra hay un icono de frambuesa 🍓. Es el Menú: ahí están todos los programas, ordenados por apartados.
  • Al lado están los iconos de los programas más útiles: el navegador (para visitar páginas web), el gestor de archivos (un icono de carpeta) y la terminal (una pantallita negra). La terminal no la vamos a necesitar.
  • A la derecha de la barra están el reloj, el volumen y la red.
💡 Cómo manejar las ventanas Cada programa abierto tiene una ventana. Arriba de la ventana está la barra de título, con el nombre y tres botones a la derecha: — ocultar, □ ocupar toda la pantalla, × cerrar. Para mover una ventana, arrástrala con el ratón por la barra de título. Para cambiar su tamaño, arrastra un borde o una esquina.

2. Un teclado de programador

Los programas se escriben con letras normales y muchos símbolos distintos: ( ) { } [ ] ; " = < >. Puede que algunos no los hayas escrito nunca. ¡Vamos a buscarlos!

Dónde se esconden los símbolos

Escribir Mayús + 8 significa «mantén pulsada la tecla Mayús (la flecha gorda ⇧) y, sin soltarla, pulsa 8». AltGr es la tecla que está a la derecha de la barra espaciadora. La tabla es para un teclado español de España.

💡 ¿Teclado latinoamericano? En los teclados latinoamericanos algunos símbolos están en otro sitio. Fíjate en los dibujos de las teclas: el símbolo de abajo a la derecha suele salir con AltGr, y el de arriba, con Mayús.
⚠️ Teclas «muertas» y Bloq Mayús Las teclas de los acentos (´ y `) son «muertas»: al pulsarlas no aparece nada hasta que pulsas otra tecla, porque esperan una vocal para escribir á o à. Si te pasa sin querer, pulsa la barra espaciadora. Y si de repente todo sale en MAYÚSCULAS, has activado Bloq Mayús: púlsala otra vez. ¡En el código, las mayúsculas y las minúsculas son distintas!

Teclas importantes

  • Intro — línea nueva.
  • Retroceso (la flecha larga ←) — borra el carácter a la izquierda del cursor; Supr — a la derecha.
  • Tab — sangría (mover la línea a la derecha).
  • Las flechas ← ↑ → ↓ — mueven el cursor (la rayita que parpadea) por el texto.
  • Ctrl + Z — deshacer lo último. ¡Tu botón mágico de «volver atrás»!
🎯 Práctica (5 minutos) Abre Menú → Accesorios → Editor de textos (o cualquier otro editor de texto) y escribe: 
( ) { } [ ] < > ; : " ' = + * !
Después cierra el editor. Cuando pregunte «¿Guardar?», puedes contestar «No»: solo era práctica.

3. Una carpeta para tus programas

El ordenador lo guarda todo en archivos: fotos, música, programas. Los archivos están dentro de carpetas, como hojas en los cajones de una mesa. Vamos a hacer un cajón para todos los programas de este curso.

  1. Haz clic en el icono del gestor de archivos (una carpeta) en la barra de tareas. Se abre tu carpeta personal. Es tu sitio en el ordenador; ya tiene carpetas como «Documentos» y «Descargas».
  2. Haz clic con el botón derecho del ratón en un sitio vacío de la ventana (no encima de una carpeta).
  3. En el menú elige Crear nuevo… → Carpeta (en inglés Create New… → Folder).
  4. Escribe el nombre codigo (sin tilde) y pulsa Intro o Aceptar.

Hecho: junto a las demás ha aparecido una carpeta llamada codigo. Todos los programas del curso vivirán en ella.

💡 ¿Por qué sin tildes ni espacios? A los programas les gustan los nombres de archivos y carpetas escritos con letras minúsculas sin tildes ni eñes, y sin espacios. Siempre llamaremos así a los archivos: prueba.html, snake.html (snake es «serpiente» en inglés).

4. El editor de código Geany

Puedes escribir código en cualquier editor de texto, pero es más fácil en uno especial para programar. Colorea el código, numera las líneas y pone las sangrías por ti. Usaremos Geany: es sencillo y va rápido en una Raspberry Pi.

Busca Geany

Abre Menú 🍓 → Programación. Si ahí está Geany, perfecto: pasa a la configuración.

Si Geany no está, hay que instalarlo (llama a una persona adulta, quizá haga falta una contraseña):

  1. Menú → Preferencias → Software recomendado (Preferences → Recommended Software).
  2. A la izquierda elige el apartado Programación (Programming).
  3. Busca Geany en la lista y márcalo.
  4. Pulsa Aplicar (Apply) y espera a que termine la instalación.
👨‍👩‍👧 Para personas adultas Si en el menú no aparece «Software recomendado», instalad Geany desde la terminal con sudo apt install geany.

Configura Geany

Abre Geany: Menú → Programación → Geany. Los menús aparecen aquí en español y, entre paréntesis, en inglés: en tu ordenador puede salir cualquiera de las dos versiones.

  1. Letra grande. Editar → Preferencias (Edit → Preferences) → pestaña Interfaz (Interface) → Tipografías (Fonts) → la línea Editor. Pulsa el botón de la letra y pon el tamaño 16 o 18. También puedes agrandar la letra con Ctrl + + y achicarla con Ctrl + -.
  2. Sangría. En las mismas preferencias: pestaña Editor → Sangría (Indentation). Pon Anchura: 2 (Width) y Tipo: Espacios (Type: Spaces). Pulsa Aceptar.
  3. Quitamos lo que sobra. En el menú Ver (View) desmarca Mostrar barra lateral (Show Sidebar) y Mostrar ventana de mensajes (Show Message Window). Así queda sitio solo para el código.
  4. Números de línea. A la izquierda del texto debe haber números de línea: 1, 2, 3… Si no están, actívalos en Ver → Mostrar números de línea (View → Show Line Numbers).
💡 No tengas miedo de pulsar Si en el editor desaparece algo o se ve raro, no se ha roto nada. Cierra Geany y vuelve a abrirlo, o pide ayuda a una persona adulta.

5. El navegador

Nuestros programas los ejecutará un navegador, el mismo programa con el que se visitan páginas web. Usaremos Firefox: su icono es un zorro naranja. Búscalo en la barra de tareas o en Menú → Internet y ábrelo.

👨‍👩‍👧 Para personas adultas Poned Firefox como navegador predeterminado para que los archivos .html se abran en él con doble clic. En Raspberry Pi OS se hace en Menú → Preferencias → Control Centre / Configuración de Raspberry Pi, pestaña System, opción Browser → Firefox. Si Firefox no está instalado, está en Software recomendado (apartado Internet).

6. Colocamos las ventanas

Quien programa mira todo el rato el código y luego el resultado. Pon las ventanas una al lado de la otra: Geany a la izquierda y el navegador a la derecha. Arrástralas por la barra de título y mueve los bordes para que cada una ocupe media pantalla.

Compruébalo

  • Sé escribir { } ( ) ; ".
  • En mi carpeta personal hay una carpeta llamada codigo.
  • Geany se abre, la letra es grande y la sangría es de 2 espacios.
  • Sé abrir Firefox y poner las ventanas una al lado de la otra.
🎉 ¡Tu sitio de trabajo está listo! Todo preparado. En la próxima lección escribiremos nuestro primer programa.
