Preparamos el ordenador

Antes de escribir un juego, vamos a preparar el sitio de trabajo: instalaremos un editor de código y un navegador, crearemos una carpeta para nuestros programas y buscaremos dónde se esconden las llaves y los corchetes en el teclado. El curso sirve para cualquier ordenador: Windows, macOS o Linux.

En esta lección vas a:
  • descubrir qué sistema tiene tu ordenador y dónde están sus programas;
  • crear una carpeta llamada codigo para tus programas;
  • instalar y configurar el editor Geany y el navegador Firefox;
  • encontrar los símbolos «de programador» en el teclado;
  • colocar las ventanas para trabajar con comodidad.

Sirve cualquier ordenador: con Linux (por ejemplo, Raspberry Pi OS o Ubuntu), macOS o Windows. Instalamos dos programas gratuitos que se ven igual en todos los sistemas: el editor Geany y el navegador Firefox. Por eso todas las demás lecciones son iguales para todos; solo cambia esta.

Es mejor hacer esta lección juntos: para instalar programas pueden hacer falta una contraseña y permisos de administrador. Es cómodo crear un usuario propio para la niña o el niño.

1. ¿Qué ordenador tienes?

Cada ordenador funciona con un sistema operativo: el programa principal, que muestra el escritorio, las ventanas y los menús. Los más conocidos son Windows, macOS (en los ordenadores Apple) y Linux (por ejemplo, en los ordenadores pequeñitos Raspberry Pi o con Ubuntu).

Abajo hay un apartado para cada sistema. El de tu sistema suele abrirse solo. Si no, ábrelo con un clic. No hace falta leer los demás.

💡 Cómo manejar las ventanas (en cualquier sistema) Cada programa abierto tiene una ventana. Arriba está la barra de título, con el nombre y unos botones: minimizar, ocupar toda la pantalla y cerrar (×). Para mover una ventana, arrástrala por la barra de título. Para cambiar su tamaño, arrastra un borde o una esquina.
🍓 Raspberry Pi OS (Linux)

El escritorio

Arriba de la pantalla está la barra de tareas. En su esquina izquierda hay un icono de frambuesa 🍓: es el Menú con todos los programas. Al lado están los iconos del navegador y del gestor de archivos (una carpeta).

Una carpeta para tus programas

  1. Pulsa el icono del gestor de archivos y abre la carpeta Documentos (Documents).
  2. Haz clic con el botón derecho en un sitio vacío y elige Crear nuevo… → Carpeta (Create New… → Folder).
  3. Llámala codigo (sin tilde) y pulsa Intro.

Geany y Firefox

Muchas veces Geany ya está: Menú → Programación → Geany. Firefox está en Menú → Internet. Si falta alguno:

  1. Menú → Preferencias → Software recomendado (Recommended Software).
  2. Geany está en el apartado Programación y Firefox en Internet. Márcalo.
  3. Pulsa Aplicar (Apply) y espera a que termine la instalación.
👨‍👩‍👧 Para personas adultasDesde la terminal: sudo apt install geany firefox. El navegador predeterminado se elige en Control Centre, pestaña System, opción Browser. Comprobad ahí también que la distribución del teclado coincide con el teclado físico (España o Latinoamérica).
🐧 Ubuntu y otros Linux

El escritorio

A la izquierda o abajo está el dock con los iconos de los programas. El botón Mostrar aplicaciones (un cuadrado de puntos) abre todos los programas, y tiene buscador: empieza a escribir el nombre. Las carpetas se abren con el programa Archivos.

Una carpeta para tus programas

  1. Abre Archivos y entra en la carpeta Documentos.
  2. Haz clic con el botón derecho en un sitio vacío → Nueva carpeta.
  3. Llámala codigo y pulsa Crear.

Geany y Firefox

Firefox ya viene con Ubuntu. Geany se instala así:

  1. Abre el Centro de aplicaciones (App Center o Ubuntu Software).
  2. Busca Geany y pulsa Instalar. Si pide contraseña, llama a una persona adulta.
  3. Abre Geany desde Mostrar aplicaciones: empieza a escribir «geany».
👨‍👩‍👧 Para personas adultasDesde la terminal: sudo apt install geany (en Fedora: sudo dnf install geany). Navegador predeterminado: Configuración → Aplicaciones predeterminadas → Web.
🍏 macOS (ordenadores Apple)

El escritorio

Abajo de la pantalla está el Dock con los iconos de los programas. Cualquier programa se encuentra con Spotlight: pulsa ⌘ Cmd + Espacio y empieza a escribir el nombre. Las carpetas se abren con el Finder (el icono azul sonriente).

Una carpeta para tus programas

  1. Abre el Finder y elige Documentos a la izquierda.
  2. Haz clic con el botón derecho (o Ctrl + clic) en un sitio vacío → Nueva carpeta.
  3. Llámala codigo y pulsa Retorno.

Geany y Firefox

  1. Geany: en geany.org abre Download → Releases y descarga el archivo para macOS (.dmg). Ábrelo y arrastra el icono de Geany a Aplicaciones.
  2. Firefox: descárgalo de mozilla.org y arrástralo también a Aplicaciones.
  3. Si la primera vez macOS no deja abrir un programa, haz clic derecho sobre él en Aplicaciones → Abrir → Abrir. O bien: Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.
⌘ En un Mac, Cmd en lugar de Ctrl En las lecciones pone Ctrl + S; en un Mac pulsa ⌘ Cmd + S. Lo mismo con N, O, Z y +. En el navegador, la página se recarga con ⌘ + R (en lugar de F5) y la consola se abre con ⌘ + ⌥ Opción + K. La tabla completa está en la chuleta. En el teclado español de Mac algunos símbolos están en otro sitio: fíjate en los dibujos de las teclas, la tecla ⌥ Opción hace el papel de AltGr.
👨‍👩‍👧 Para personas adultasCon Homebrew: brew install --cask geany firefox. Navegador predeterminado: Ajustes del Sistema → Escritorio y Dock → Navegador web por omisión.
🪟 Windows

El escritorio

Abajo de la pantalla está la barra de tareas. El botón Inicio (el logotipo de Windows) abre todos los programas y tiene buscador: empieza a escribir el nombre. Las carpetas se abren con el Explorador de archivos (la carpeta amarilla).

Una carpeta para tus programas

  1. Abre el Explorador de archivos y elige Documentos a la izquierda.
  2. Haz clic con el botón derecho en un sitio vacío → Nuevo → Carpeta.
  3. Llámala codigo y pulsa Intro.
⚠️ Muestra las extensiones Windows esconde la terminación de los nombres de archivo, y en lugar de prueba.html verás solo prueba. Actívalas: en el Explorador, Vista → Mostrar → Extensiones de nombre de archivo (en Windows 10: pestaña Vista → marca Extensiones de nombre de archivo).

Geany y Firefox

  1. Geany: en geany.org abre Download → Releases y descarga el instalador para Windows (el archivo que termina en _setup.exe). Ejecútalo y pulsa Siguiente dejándolo todo como está.
  2. Firefox: descárgalo de mozilla.org e instálalo igual.
  3. Los dos programas aparecen en el menú Inicio.
👨‍👩‍👧 Para personas adultasDescargad los programas solo de sus webs oficiales. Desde la terminal: winget install Geany.Geany Mozilla.Firefox. Navegador predeterminado: Configuración → Aplicaciones → Aplicaciones predeterminadas → Firefox.

2. Un teclado de programador

Los programas se escriben con letras normales y muchos símbolos distintos: ( ) { } [ ] ; " = < >. Puede que algunos no los hayas escrito nunca. ¡Vamos a buscarlos!

Dónde se esconden los símbolos

Escribir Mayús + 8 significa «mantén pulsada la tecla Mayús (la flecha gorda ⇧) y, sin soltarla, pulsa 8». AltGr es la tecla que está a la derecha de la barra espaciadora. La tabla es para un teclado español de España de PC.

SímboloNombreCómo escribirlo
( )paréntesisMayús + 8 y Mayús + 9
{ }llavesAltGr + la tecla ´ (a la derecha de la Ñ) y AltGr + la tecla Ç
[ ]corchetesAltGr + la tecla ` (a la derecha de la P) y AltGr + la tecla +
< >menor que, mayor quela tecla a la izquierda de la Z; con Mayús sale >
;punto y comaMayús + ,
:dos puntosMayús + .
"comillas doblesMayús + 2
'comilla simple (apóstrofo)la tecla a la derecha del 0
/barraMayús + 7
=igualMayús + 0
+ y *más y asterisco (por)la tecla + (a la izquierda de Intro); con Mayús sale *
- y _menos y guion bajola tecla a la izquierda de Mayús derecha; con Mayús sale _
!exclamaciónMayús + 1
&et («y»)Mayús + 6
|barra vertical («o»)AltGr + 1
💡 ¿Teclado latinoamericano o de Mac? En los teclados latinoamericanos y de Mac algunos símbolos están en otro sitio. Fíjate en los dibujos de las teclas: el símbolo de abajo a la derecha suele salir con AltGr (en Mac, con ⌥ Opción), y el de arriba, con Mayús.
⚠️ Teclas «muertas» y Bloq Mayús Las teclas de los acentos (´ y `) son «muertas»: al pulsarlas no aparece nada hasta que pulsas otra tecla, porque esperan una vocal para escribir á o à. Si te pasa sin querer, pulsa la barra espaciadora. Y si de repente todo sale en MAYÚSCULAS, has activado Bloq Mayús: púlsala otra vez. ¡En el código, las mayúsculas y las minúsculas son distintas!

Teclas importantes

  • Intro — línea nueva (en Mac se llama Retorno).
  • Retroceso (la flecha larga ←) — borra el carácter a la izquierda del cursor; Supr — a la derecha.
  • Tab — sangría (mover la línea a la derecha).
  • Las flechas ← ↑ → ↓ — mueven el cursor (la rayita que parpadea) por el texto.
  • Ctrl + Z (en Mac ⌘ + Z) — deshacer lo último. ¡Tu botón mágico de «volver atrás»!

3. Configuramos Geany

Puedes escribir código en cualquier editor de texto, pero es más fácil en uno especial para programar. Colorea el código, numera las líneas y pone las sangrías por ti. Hemos elegido Geany: es sencillo, gratuito y se ve igual en todos los sistemas.

Abre Geany. Los menús aparecen aquí en español y, entre paréntesis, en inglés: en tu ordenador puede salir cualquiera de las dos versiones.

  1. Letra grande. Editar → Preferencias (Edit → Preferences; en Mac puede estar en el menú Geany) → pestaña Interfaz (Interface) → Tipografías (Fonts) → la línea Editor. Pon el tamaño 16 o 18. También puedes agrandar la letra con Ctrl + + y achicarla con Ctrl + -.
  2. Sangría. En las mismas preferencias: pestaña Editor → Sangría (Indentation). Pon Anchura: 2 (Width) y Tipo: Espacios (Type: Spaces). Pulsa Aceptar.
  3. Quitamos lo que sobra. En el menú Ver (View) desmarca Mostrar barra lateral (Show Sidebar) y Mostrar ventana de mensajes (Show Message Window). Así queda sitio solo para el código.
  4. Números de línea. A la izquierda del texto debe haber números de línea: 1, 2, 3… Si no están, actívalos en Ver → Mostrar números de línea (View → Show Line Numbers).
🎯 Práctica (5 minutos) Crea un archivo nuevo en Geany (Archivo → Nuevo) y escribe: 
( ) { } [ ] < > ; : " ' = + * !
Después cierra la pestaña. Cuando pregunte «¿Guardar?», contesta «No»: solo era práctica.
💡 No tengas miedo de pulsar Si en el editor desaparece algo o se ve raro, no se ha roto nada. Cierra Geany y vuelve a abrirlo, o pide ayuda a una persona adulta.
👨‍👩‍👧 Para personas adultas: alternativas a Geany

Hemos elegido Geany porque es ligero, gratuito e igual en Windows, macOS y Linux, y así es más fácil explicarlo. Si preferís otro editor:

  • Visual Studio Code (o su versión abierta VSCodium): el editor más popular entre quienes programan, para todos los sistemas. Muy potente, pero lleno de paneles y avisos, así que es mejor pasarse a él después del curso. En una Raspberry Pi va bastante más lento que Geany.
  • Notepad++ (solo Windows): ligero y parecido a Geany.
  • Kate o Editor de texto (gedit, GNOME Text Editor) en Linux: colorean el código, pero son menos cómodos.
  • CotEditor (solo macOS): un editor de código sencillo y gratuito.

No sirven: el Bloc de notas de Windows y TextEdit de macOS: no colorean el código ni numeran las líneas, y TextEdit guarda por defecto texto con formato, que el navegador no entiende. Tampoco sirven Word ni otros procesadores de texto.

4. Colocamos las ventanas

Nuestros programas los ejecutará Firefox, el mismo programa con el que se visitan páginas web. Quien programa mira todo el rato el código y luego el resultado. Pon las ventanas una al lado de la otra: Geany a la izquierda y Firefox a la derecha. Arrástralas por la barra de título y mueve los bordes para que cada una ocupe media pantalla.

💡 Forma rápida En Windows y Ubuntu puedes pegar una ventana a media pantalla con Win (Super) + ← o →. En un Mac, deja el puntero sobre el botón verde de la esquina de la ventana y elige una distribución.

Compruébalo

  • Sé qué sistema tiene mi ordenador.
  • En Documentos hay una carpeta llamada codigo.
  • Geany se abre, la letra es grande y la sangría es de 2 espacios.
  • Firefox está instalado y sé poner las ventanas una al lado de la otra.
  • Sé escribir { } ( ) ; ".
🎉 ¡Tu sitio de trabajo está listo! A partir de aquí, todas las lecciones son iguales en cualquier ordenador. En la próxima escribiremos nuestro primer programa.
