Variables

A game has lots to remember: the score, the length of the snake, the speed. For that, programs have variables — labelled boxes where you can keep numbers and text.

In this lesson you will:
  • create variables with the let command;
  • learn to change what's inside a variable;
  • glue text together from pieces;
  • write a program that asks for your name.

A box with a label

Imagine a box with the word score written on it. Let's put the number 0 in it:

let score = 0;
  • let — "let there be": we're making a new box;
  • score — the box's name (its label);
  • = — "put into it";
  • 0 — what we put in.

Now, wherever we write score, the computer will use whatever is in the box.

Open test.html, delete everything between <script> and </script>, and write:

let score = 0;
console.log(score);

score = 10;
console.log(score);

score = score + 1;
console.log(score);

Save, refresh and look in the console: 0, 10, 11.

Wait, score = score + 1?!

In maths that's impossible: a number can't equal itself plus one. But in programming = doesn't mean "equals", it means "put in the box". The computer reads this line from right to left:

  1. it takes what's in score (that's 10);
  2. adds 1 (that makes 11);
  3. puts the result back into score.

That's exactly how the score in our game will grow when the snake eats an apple!

⚠️ Write let only once let is only needed when we create a box. When we change what's inside, we just write score = 10;. If you write let score a second time, you'll get the error redeclaration of let score: "the box score is being declared again — it already exists".

Rules for names

  • Only English letters, digits and _. No spaces. A name can't start with a digit.
  • Capital and small letters are different: score and Score are two different boxes.
  • If a name has several words, start each word after the first with a capital letter: snakeLength, bestScore. It looks like a camel's humps, so this style is called "camelCase".
  • Choose clear names: speed is better than s or abc.

Text in variables

You can put text (a string) in a variable too:

let name = "Alex";
console.log("Hello, " + name + "!");

If you add strings with +, they glue together into one: Hello, Alex!. Don't forget the space inside the quotes after the comma, or you'll get "Hello,Alex!".

And what if you glue text and a number?

let apples = 5;
console.log("Apples eaten: " + apples);
console.log("5" + 5);
console.log(5 + 5);

You get Apples eaten: 5, then 55 (the text "5" and the number 5 got glued together), and 10 (two numbers were added). Remember: quotes turn a number into text.

A chatty program

The prompt command shows a window where you can type something. Whatever the person types can go straight into a variable:

let name = prompt("What's your name?");
alert("Hello, " + name + "! Let's write a game.");

let year = 2026;
let born = prompt("What year were you born?");
alert("You are about " + (year - born) + " years old.");

The expression (year - born) is in brackets so that the computer first works out the difference, and only then glues it to the text.

💡 Is it a different year now? If it's no longer 2026, put the current year in year.

🎯 Tasks
  1. Create a variable lives with the value 3. Take away one life (lives = lives - 1;) and print the result to the console.
  2. Ask the player for their favourite animal and print: "My favourite animal is …".
  3. Make variables width = 20 and height = 15. Work out how many squares the field has, width × height, and print the answer with an explanation.
  4. ⭐ Write score++; instead of score = score + 1;. Does it work? It's a shorthand, and we'll need it later.
