Your first program

Today you'll create your first code file, and the computer will say hello to you. You'll also learn the main loop every programmer uses: write → save → refresh.

In this lesson you will:
  • create a file called test.html in Geany and save it in the code folder;
  • write a page in HTML and your first JavaScript command;
  • open your program in the browser;
  • learn to check your changes quickly.

How it works

We'll write files whose names end in .html. A browser knows how to open them. Two languages live in such a file:

  • HTML describes what is on the page: headings, text, a field for the game.
  • JavaScript (JS for short) describes what to do: show messages, count, move the snake.

We write text in the editor, and the browser reads it and carries it out. That's all the magic.

Step 1. Create a file

  1. Open Geany. If an old file is open there, close it with the cross on its tab.
  2. Choose File → New or press Ctrl + N. An empty sheet appears with an "untitled" tab.
  3. Save it straight away: File → Save As or Ctrl + Shift + S.
  4. In the save window choose your home folder on the left (the house icon), then double-click the code folder to open it.
  5. In the Name box type test.html and click Save.
💡 Why save an empty file? From the ending .html Geany learns which language you're writing in and starts colouring the code. That makes mistakes easier to spot.

Step 2. Write the code

Carefully type the code below. Don't type the line numbers — Geany adds them itself. You can indent the start of a line with the Tab key, and after Enter Geany usually indents for you.

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Test</title>
</head>
<body>
  <h1>My first program</h1>
  <script>
    alert("Hello! I'm your computer.");
  </script>
</body>
</html>
⚠️ Type it, don't copy it That way your fingers remember where the symbols are, and your head remembers the commands. If you make a mistake, no problem: hunting for typos is useful too.

Step 3. Save and run

  1. Press Ctrl + S to save. Look at the tab: if the file name was red or had a star *, it becomes normal after saving.
  2. Open the file manager and go into the code folder. Your file test.html is there.
  3. Right-click it and choose Open With… → Firefox. If Firefox is the default browser, a double click is enough.

A little window appears saying "Hello! I'm your computer." Click OK, and you'll see a page with the heading "My first program".

🎉 Congratulations! Your very first real program just ran.

Let's look at what we wrote

HTML is made of tags — words in angle brackets. Tags usually come in pairs: an opening <body> and a closing </body> (with a slash). Everything between them is "inside", like in a box.

What's writtenWhat it means
<!DOCTYPE html>"Browser, this is an HTML page." Always the first line.
<html> … </html>The biggest box: the whole page is in it.
<head> … </head>The "head": behind-the-scenes information you don't see on the page.
<meta charset="utf-8">So that all letters and symbols display correctly.
<title>The name you see on the browser tab.
<body> … </body>The "body": what you see on the page.
<h1>A big heading.
<script> … </script>JavaScript starts here!

And here is our first line of JavaScript:

alert("Hello! I'm your computer.");
  • alert is a command that shows a little window with a message.
  • In the round brackets ( ) we tell the command what to show.
  • Text is always written in quotes " ".
  • The semicolon ; at the end is like a full stop at the end of a sentence: the command is finished.

Experiments

Try these one at a time, and after each change do Ctrl + S → F5:

  1. Change the text inside the quotes in alert to your own.
  2. Change the heading text between <h1> and </h1>.
  3. Add a paragraph of text under the heading: <p>My name is …</p>. The <p> tag means paragraph.
🎯 Tasks
  1. Make three little windows appear one after another: "One", "Two", "Three". To do that, write three lines with alert, one under another.
    Notice: the program runs from top to bottom, one command at a time. This is a very important rule!
  2. What happens if you remove the quotes: alert(Hello);? Try it, then put it back the way it was. (We'll find out why in the next lesson.)
  3. ⭐ Try the command alert(2 + 3); — without quotes. What does the computer show?

If it doesn't work

  • No little window appears? Check that the quotes are ordinary straight quotes " and that every bracket is in place.
  • You can't see your changes? Is the file saved (Ctrl + S)? Is the page refreshed (F5)?
  • The code isn't coloured? The file was probably saved without .html at the end of its name. Save it again with "Save As".

Check yourself

  • My file test.html is in the code folder.
  • I know that HTML describes the page and JavaScript describes actions.
  • I remember the loop: write → Ctrl+S → F5 → look.
