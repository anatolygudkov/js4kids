Arrow key controls

The snake crawls wherever it likes, and it's time it listened to the player. Let's teach the program to find out which key was pressed and turn the snake with the arrow keys.

In this lesson you will:
  • find out what events are;
  • "subscribe" to key presses with addEventListener;
  • learn what the arrow keys are called;
  • teach the snake to turn, but not to reverse.
Lesson plan
10 minEvents: spying on the keyboard
15 minThe onKey function: turning the snake
10 minNo reversing allowed
10 minPlay and do the tasks

Events

When you press a key, move the mouse or click a button, the browser notices. These happenings are called events. We can ask the browser: "When a key is pressed, call my function."

Add this to the end of the script, before draw();:

function onKey(event) {
  console.log(event.key);
}

document.addEventListener("keydown", onKey);
  • "keydown" is the "a key was pressed" event.
  • addEventListener means "add a listener": now every time a key is pressed, the browser will call our function onKey.
  • The browser itself passes the parameter event to the function; it has everything about the event written in it. event.key holds the name of the key.

Save, refresh the page, open the console and click on the page with the mouse (so that it "listens" to the keyboard). Press various keys and arrows. Their names appear in the console:

ArrowUp
ArrowDown
ArrowLeft
ArrowRight
a
Enter

So ArrowUp is the up arrow.

💡 Keys not working? If you press keys and nothing shows up in the console, click on the page itself, for example on the black field. Keys go to the window or the part of the screen you clicked last.

Turning

Now instead of console.log we'll change the direction dx and dy. Remember the table of directions from lesson 8? Replace the onKey function:

function onKey(event) {
  console.log(event.key);
  if (event.key === "ArrowUp") {
    dx = 0;
    dy = -1;
  }
  if (event.key === "ArrowDown") {
    dx = 0;
    dy = 1;
  }
  if (event.key === "ArrowLeft") {
    dx = -1;
    dy = 0;
  }
  if (event.key === "ArrowRight") {
    dx = 1;
    dy = 0;
  }
}

Save, refresh, click on the field and steer with the arrows! 🎮

The name of a key is text, so "ArrowUp" is written in quotes. Capital letters matter: "arrowup" won't work.

No going back!

Try this: the snake is crawling right and you press the left arrow. The snake turns around and crawls straight through itself. In a real Snake game that's not allowed: the head would crash into its own body.

The rule is: you can turn up only if the snake isn't crawling down right now. Crawling down means dy is 1. Let's add that to the condition with && ("and"):

function onKey(event) {
  if (event.key === "ArrowUp" && dy !== 1) {
    dx = 0;
    dy = -1;
  }
  if (event.key === "ArrowDown" && dy !== -1) {
    dx = 0;
    dy = 1;
  }
  if (event.key === "ArrowLeft" && dx !== 1) {
    dx = -1;
    dy = 0;
  }
  if (event.key === "ArrowRight" && dx !== -1) {
    dx = 1;
    dy = 0;
  }
}

Let's read the first condition in plain English: "If the up arrow is pressed and the snake isn't crawling down, then turn up."

🎯 Tasks

  2. Make the snake faster (an interval of 120) and try steering it. What about 60?
  3. ⭐ Lots of games use the W A S D keys. Add them. Here's a trick: if Caps Lock is on, event.key for the W key will be "W", not "w"! So use event.code — that's the key's "place" on the keyboard, and it doesn't depend on Caps Lock or the keyboard language: "KeyW", "KeyA", "KeyS", "KeyD". Hint: you can extend the condition with ||: 
    if ((event.key === "ArrowUp" || event.code === "KeyW") && dy !== 1) {
📄 The whole snake.html file after this lesson 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Snake</title>
</head>
<body>
  <h1>Snake</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x >= cells) {
        head.x = 0;
      }
      if (head.x < 0) {
        head.x = cells - 1;
      }
      if (head.y >= cells) {
        head.y = 0;
      }
      if (head.y < 0) {
        head.y = cells - 1;
      }

      snake.unshift(head);
      snake.pop();
      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        dx = 0;
        dy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        dx = 0;
        dy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        dx = -1;
        dy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        dx = 1;
        dy = 0;
      }
    }

    document.addEventListener("keydown", onKey);
    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
