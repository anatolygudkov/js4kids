Lesson 4 of 16 ⏱ 45 minutes

Canvas and coordinates

The game begins! Let's create a file called snake.html — the Snake will live in it until the very end of the course. Today we'll draw the playing field, the snake's head and an apple.

In this lesson you will:
  • create the game file snake.html;
  • add a <canvas> to the page;
  • find out how the computer counts coordinates;
  • draw coloured rectangles.
Lesson plan
10 minCreate snake.html and the canvas
10 minCoordinates: where x is, where y is
10 minDraw the field, the head and the apple
15 minDraw your own picture out of rectangles

A new file for the game

Create a new file in Geany (Ctrl + N) and save it straight away in the code folder as snake.html (Ctrl + Shift + S). Type the code:

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Snake</title>
</head>
<body>
  <h1>Snake</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");

    ctx.fillStyle = "black";
    ctx.fillRect(0, 0, 400, 400);

    ctx.fillStyle = "lime";
    ctx.fillRect(200, 200, 20, 20);

    ctx.fillStyle = "red";
    ctx.fillRect(300, 100, 20, 20);
  </script>
</body>
</html>

Save it and open snake.html in the browser (through the file manager, like in the first lesson). You'll see a black field, a green square (this will be the snake's head) and a red square (the apple).

What's written here

The canvas

<canvas id="game" width="400" height="400"></canvas>

<canvas> is a place for drawing. Its width and height are 400 dots. Each such dot on the screen is called a pixel. And id="game" is the canvas's name, so that JavaScript can find it.

The paintbrush

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
  • document.getElementById("game") — "find the element named game on the page (the document)". We put the canvas we found into the variable canvas.
  • canvas.getContext("2d") — "give me the tools for flat (2D) drawing". We put them into the variable ctx. From now on ctx is our paintbrush.

You can simply memorise these two lines: they're needed at the start of any program that draws on a canvas.

Drawing

ctx.fillStyle = "lime";
ctx.fillRect(200, 200, 20, 20);
  • fillStyle — which colour to paint with. First we dip the brush in paint.
  • fillRect(x, y, width, height) — draw a filled rectangle.

You can write colours as English words: "red", "green", "lime", "blue", "yellow", "orange", "purple", "pink", "white", "black", "gray", "brown".

Coordinates

To say where to draw, you need two numbers: x — how many pixels to move right from the left edge, and y — how many pixels to move down from the top edge.

⚠️ Not like in maths! In maths lessons the y axis points up, but on a computer screen it points down. The bigger y is, the lower on the screen.

Now it's clear what each line with fillRect means:

  • fillRect(0, 0, 400, 400) — from the top left corner, fill a 400 by 400 square — that's the whole canvas.
  • fillRect(200, 200, 20, 20) — move 200 right and 200 down and draw a 20 by 20 square.
💡 Order matters The computer draws in the order the code is written: new things go on top of old ones, like paint on paper. Try moving the lines with the black field to the very end of the script. Where did the squares go?
🎯 Tasks
  1. Move the apple to the bottom left corner of the field.
  2. Draw two more squares behind the head to make a snake of three pieces: (180, 200) and (160, 200).
  3. Draw a traffic light: a grey rectangle and three coloured squares. Then delete it or comment it out (see the tip below) — the game doesn't need it.
  4. ⭐ You can also give a colour as a code: "#ff8800" is orange. Try different letters and digits from 0 to f after the hash sign.
💡 Comments If you put two slashes // at the start of a line, the computer skips that line. It's a comment — a note for people. You can use it to leave yourself explanations or to "switch off" lines of code for a while. 
// This is the snake's head
ctx.fillStyle = "lime";
