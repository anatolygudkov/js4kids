Loops

How do you draw a row of 20 cells? You could write 20 lines with drawCell… Or just one, if you ask the computer to repeat. Repetition in programming is called a loop.

In this lesson you will:
  • learn the for loop and what parts it's made of;
  • follow, step by step, how a loop works;
  • draw rows, columns and diagonals of cells.

Counting to five

for (let i = 0; i < 5; i++) {
  console.log("Step number " + i);
}

Open the console (F12) and refresh the page:

One line inside the loop ran 5 times, and each time the variable i held a new number.

What a for loop is made of

In the round brackets after for there are three parts, separated by semicolons:

PartWhat it means
let i = 0Start: create a counter i and put 0 in it.
i < 5Condition: keep repeating while i is less than 5.
i++Step: after each round, add one to i (the same as i = i + 1).

And inside the curly brackets { } is the body of the loop — what needs repeating.

Let's follow how the computer runs the loop:

  1. i = 0. Is 0 < 5 true? Yes → run the body → i++, now i = 1.
  2. 1 < 5? Yes → body → i = 2.
  3. … the same for 2, 3 and 4 …
  4. i = 5. 5 < 5? No → the loop is over, carry on with the program.
💡 Why i? It's a tradition: i is the first letter of the word index ("number"). You can call the counter anything you like, but every programmer understands i.

Drawing with a loop

Replace the loop with console.log with this one:

for (let i = 0; i < 20; i++) {
  drawCell(i, 0, "gray");
}

A grey row of 20 cells appeared along the top edge! Each time round, i gets bigger and the next cell is drawn further right: (0, 0), (1, 0), (2, 0)… (19, 0).

The number 20 is the number of cells in a row, and we'll need it many more times. Let's put it in a variable. Add it right under let size = 20;:

let cells = 20;

Now in the loop you can write i < cells. If one day you want a bigger field, you'll only have to change one number.

Try it yourself

Change the line inside the loop and see what you get:

Inside the loopWhat gets drawn
drawCell(i, 0, "gray");a row along the top
drawCell(i, 19, "gray");a row along the bottom
drawCell(0, i, "gray");a column on the left
drawCell(i, i, "yellow");a diagonal from corner to corner

You can write several commands inside one loop. For example, this loop draws a frame around the whole field:

for (let i = 0; i < cells; i++) {
  drawCell(i, 0, "gray");
  drawCell(i, 19, "gray");
  drawCell(0, i, "gray");
  drawCell(19, i, "gray");
}
⚠️ An endless loop If the condition is always true (for example, if you forget i++), the loop never ends and the page "freezes". No big deal: close the browser tab, fix the code and open the file again.

Tidying up

Those were experiments. Before the next lesson delete all the loops that draw on the field, but keep the cells variable. It should end up like this:

📄 The whole snake.html file after this lesson 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Snake</title>
</head>
<body>
  <h1>Snake</h1>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    clearField();
    drawCell(10, 10, "lime");
    drawCell(9, 10, "lime");
    drawCell(8, 10, "lime");
    drawCell(15, 10, "red");
  </script>
</body>
</html>
