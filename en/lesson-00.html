Setting up the computer

Before we write a game, let's get our workplace ready: install a code editor and a browser, make a folder for our programs and find where the brackets hide on the keyboard. The course works on any computer — Windows, macOS or Linux.

In this lesson you will:
  • find out which system your computer runs and where its programs are;
  • create a folder called code for your programs;
  • install and set up the Geany editor and the Firefox browser;
  • find the "programmer" symbols on the keyboard;
  • arrange the windows so they're comfortable to work with.

👨‍👩‍👧 For grown-ups

Any computer will do: Linux (for example Raspberry Pi OS or Ubuntu), macOS or Windows. We install two free programs that look the same on every system: the Geany editor and the Firefox browser. That's why all the other lessons are the same for everyone — only this one differs.

It's best to do this lesson together: installing programs may need a password and administrator rights. It's handy to create a separate user account for your child.

1. Which computer do you have?

Every computer runs an operating system — the main program that shows the desktop, windows and menus. The best-known ones are Windows, macOS (on Apple computers) and Linux (for example on little Raspberry Pi computers, or Ubuntu).

Below there's a section for each system. Your system's section usually opens by itself. If it doesn't, click to open it. You don't need to read the others.

💡 How to handle windows (on any system) Every open program has a window. At the top of the window is the title bar with the name and buttons: minimise, fill the screen and close (×). To move a window, drag it by its title bar. To resize it, drag an edge or a corner.
🍓 Raspberry Pi OS (Linux)

The desktop

Along the top of the screen is the taskbar. In its left corner is a raspberry icon 🍓 — that's the Menu with all the programs. Next to it are icons for the browser and the file manager (a folder).

A folder for your programs

  1. Click the file manager icon on the taskbar and open the Documents folder.
  2. Right-click an empty spot and choose Create New… → Folder.
  3. Call it code and press Enter.

Geany and Firefox

Geany is often already there: Menu → Programming → Geany. Firefox is in Menu → Internet. If a program is missing:

  1. Menu → Preferences → Recommended Software.
  2. Geany is in the Programming section, Firefox in Internet. Tick it.
  3. Click Apply and wait for the installation to finish.
👨‍👩‍👧 For grown-upsFrom the terminal: sudo apt install geany firefox. Choose the default browser in Control Centre, System tab, Browser. Check that the keyboard layout matches the physical keyboard (US or UK) in the same Control Centre.
🐧 Ubuntu and other Linux

The desktop

On the left or at the bottom is the dock with program icons. The Show Apps button (a square of dots) opens all programs, and you can search — just start typing a name. Folders are opened by the Files program.

A folder for your programs

  1. Open Files and go into the Documents folder.
  2. Right-click an empty spot → New Folder.
  3. Call it code and click Create.

Geany and Firefox

Firefox comes with Ubuntu. To install Geany:

  1. Open the App Center (or Ubuntu Software).
  2. Search for Geany and click Install. If it asks for a password, call a grown-up.
  3. Start Geany from Show Apps: just start typing "geany".
👨‍👩‍👧 For grown-upsFrom the terminal: sudo apt install geany (on Fedora: sudo dnf install geany). Default browser: Settings → Default Applications → Web.
🍏 macOS (Apple computers)

The desktop

At the bottom of the screen is the Dock with program icons. You can find any program with Spotlight: press ⌘ Cmd + Space and start typing its name. Folders are opened by Finder (the blue smiling icon).

A folder for your programs

  1. Open Finder and choose Documents on the left.
  2. Right-click (or Ctrl + click) an empty spot → New Folder.
  3. Call it code and press Return.

Geany and Firefox

  1. Geany: on geany.org open Download → Releases and download the macOS file (.dmg). Open it and drag the Geany icon into Applications.
  2. Firefox: download it from mozilla.org and drag it into Applications too.
  3. If macOS won't open a program the first time, right-click it in Applications → Open → Open. Or: System Settings → Privacy & Security → Open Anyway.
⌘ On a Mac, Cmd instead of Ctrl The lessons say Ctrl + S; on a Mac press ⌘ Cmd + S. The same goes for N, O, Z, +. In the browser, refresh the page with ⌘ + R (instead of F5) and open the console with ⌘ + ⌥ Option + K. The full table is in the cheat sheet.
👨‍👩‍👧 For grown-upsWith Homebrew: brew install --cask geany firefox. Default browser: System Settings → Desktop & Dock → Default web browser.
🪟 Windows

The desktop

At the bottom of the screen is the taskbar. The Start button (the Windows logo) opens all programs, and you can search — just start typing a name. Folders are opened by File Explorer (the yellow folder).

A folder for your programs

  1. Open File Explorer and choose Documents on the left.
  2. Right-click an empty spot → New → Folder.
  3. Call it code and press Enter.
⚠️ Show file extensions Windows hides the endings of file names, so instead of test.html you'll see just test. Turn them on: in File Explorer, View → Show → File name extensions (in Windows 10: the View tab → tick File name extensions).

Geany and Firefox

  1. Geany: on geany.org open Download → Releases and download the Windows installer (the file ending in _setup.exe). Run it and keep clicking Next, leaving everything as it is.
  2. Firefox: download it from mozilla.org and install it the same way.
  3. Both programs appear in the Start menu.
👨‍👩‍👧 For grown-upsOnly download programs from their official websites. From the terminal: winget install Geany.Geany Mozilla.Firefox. Default browser: Settings → Apps → Default apps → Firefox.

2. A programmer's keyboard

Programs are written with ordinary letters and lots of different symbols: ( ) { } [ ] ; " = < >. Some of them you may never have typed before. Let's find them!

Where the symbols hide

Writing Shift + 9 means "hold down Shift and, without letting go, press 9". The table is for a US keyboard; differences on a UK keyboard are noted below it.

SymbolNameHow to type it
( )round brackets (parentheses)Shift + 9 and Shift + 0
{ }curly brackets (braces)Shift + [ and Shift + ] (the keys to the right of P)
[ ]square bracketsthe keys to the right of P, without Shift
< >angle brackets ("less than", "greater than")Shift + , and Shift + .
;semicolonthe key to the right of L
:colonShift + ;
"double quoteShift + ' (the key two to the right of L)
'single quotethe key two to the right of L
/slashthe key to the left of the right Shift
= and +equals and plusthe key to the left of Backspace; with Shift it's plus
- and _minus and underscorethe key to the right of 0; with Shift it's underscore
*asterisk (times)Shift + 8
!exclamation markShift + 1
&ampersand ("and")Shift + 7
|vertical bar ("or")Shift + \ (usually above Enter)
💡 UK keyboard? On a UK keyboard " is Shift + 2, and | is Shift + \ — but the \ key is next to the left Shift. Everything else is the same.
⚠️ Watch out for Caps Lock If all your letters suddenly come out as CAPITALS, you've switched on Caps Lock. Press it once more to switch it off. In code, capital and small letters are different!

Important keys

  • Enter — new line (on a Mac this key is called Return).
  • Backspace — delete the character to the left of the cursor; Delete — to the right.
  • Tab — indent (move the line to the right).
  • The arrows ← ↑ → ↓ — move the cursor (the blinking line) around the text.
  • Ctrl + Z (on a Mac ⌘ + Z) — undo the last action. Your magic "go back" button!

3. Setting up Geany

You can write code in any text editor, but it's easier in a special editor for programmers. It colours the code, numbers the lines and indents for you. We chose Geany (say "jee-nee"): it's simple, free, and looks the same on every system.

Open Geany and set it up:

  1. Big font. Edit → Preferences (on a Mac it may be in the Geany menu) → Interface tab → Fonts → the Editor line. Set the size to 16 or 18. You can also make the font bigger with Ctrl + + and smaller with Ctrl + -.
  2. Indentation. In the same preferences: Editor tab → Indentation. Set Width: 2 and Type: Spaces. Click OK.
  3. Tidy up. In the View menu untick Show Sidebar and Show Message Window. That leaves room just for code.
  4. Line numbers. To the left of the text there should be line numbers: 1, 2, 3… If they're missing, switch them on with View → Show Line Numbers.
🎯 Practice (5 minutes) Create a new file in Geany (File → New) and type: 
( ) { } [ ] < > ; : " ' = + * !
Then close the tab. When it asks "Save?", answer "No": this was just practice.
💡 Don't be afraid to click If something in the editor disappears or looks strange, nothing is broken. Close Geany and open it again, or ask a grown-up for help.
👨‍👩‍👧 For grown-ups: alternatives to Geany

We chose Geany because it's light, free and the same on Windows, macOS and Linux — which makes explaining easier. If you'd rather use another editor:

  • Visual Studio Code (or its open build VSCodium) — the most popular editor among programmers, available everywhere. Very powerful, but full of panels and pop-ups, so it's better to switch to it after the course. Noticeably slower than Geany on a Raspberry Pi.
  • Notepad++ (Windows only) — light and similar to Geany.
  • Kate or Text Editor (gedit, GNOME Text Editor) on Linux — they highlight code but are less convenient.
  • CotEditor (macOS only) — a simple, free code editor.

Not suitable: Notepad on Windows and TextEdit on macOS — no highlighting or line numbers, and TextEdit saves formatted text by default, which the browser can't read. Word and other word processors won't work either.

4. Arranging the windows

Our programs will be run by Firefox — the same program you use to visit websites. Programmers keep looking at the code and then at the result. Put the windows side by side: Geany on the left, Firefox on the right. Drag them by their title bars and move the edges so each takes up half the screen.

💡 Quick way On Windows and Ubuntu you can snap a window to half the screen with Win (Super) + ← or →. On a Mac, hold the pointer over the green button in the window's corner and choose a layout.

Check yourself

  • I know which system my computer runs.
  • There's a code folder in Documents.
  • Geany opens, the font is big, the indent is 2 spaces.
  • Firefox is installed and I can put the windows side by side.
  • I can type { } ( ) ; ".
