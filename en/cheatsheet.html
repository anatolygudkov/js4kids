JavaScript

Output

alert("A window with a message");
console.log("A message in the console");
let name = prompt("Question?");    // the answer goes into name

Variables and maths

let score = 0;              // create a box
score = score + 1;          // change it (no let!)
score++;                    // the same, shorter
let text = "Score: " + score; // glue text together
// + - * /  — plus, minus, times, divide

Conditions

if (score > 10) {
  // if true
} else {
  // otherwise
}
// comparisons: >  <  >=  <=  ===  !==
// and: &&     or: ||     not: !

Loops

for (let i = 0; i < 10; i++) {
  // repeats 10 times, i = 0, 1, … 9
}

while (condition) {
  // repeats as long as the condition is true
}

Functions

function drawCell(x, y, color) {   // write the recipe
  // steps
}
drawCell(3, 2, "lime");            // call it

function randomCell() {
  return Math.floor(Math.random() * 20);   // return an answer
}

Objects and arrays

let apple = { x: 15, y: 10 };    // object
apple.x = 3;

let snake = [{ x: 1, y: 1 }, { x: 0, y: 1 }];  // array
snake[0]          // first element (numbers start at zero!)
snake.length      // how many elements
snake.push(a)     // add to the end
snake.unshift(a)  // add to the start
snake.pop()       // remove the last one

Canvas

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
ctx.fillStyle = "red";                 // colour
ctx.fillRect(x, y, width, height);     // rectangle
ctx.font = "32px sans-serif";          // font
ctx.fillText("Text", x, y);            // text

(0, 0) is the top left corner. x grows to the right, y grows downwards.

Time, keys, the page, memory

let timer = setInterval(step, 200);   // call step every 200 ms
clearInterval(timer);                 // stop it

document.addEventListener("keydown", onKey);
// event.key: "ArrowUp", "ArrowDown", "ArrowLeft", "ArrowRight", " ", "Enter"
// event.code: "KeyW", "KeyA", ... (doesn't depend on Caps Lock or layout)

document.getElementById("score").textContent = score;

localStorage.setItem("snakeBest", 25);
let best = Number(localStorage.getItem("snakeBest"));

Common errors

MessageWhat to check
… is not defineda typo in the name, capital/small letters, text without quotes
missing ) after argument lista ) is missing
missing } after function bodya } is missing at the end of a function, if or loop
string literal contains an unescaped line breakan unclosed quote
expected …, got … / illegal characteran extra or odd symbol
redeclaration of let …let written twice for the same variable
… is undefinedusing an array element that doesn't exist, for example snake[5] when the snake has three pieces
Nothing changesIs the file saved? Is the page refreshed (F5)? Is it the right file?
