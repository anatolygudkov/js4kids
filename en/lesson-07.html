Arrays and objects

Right now the snake is drawn with three separate commands. But it's going to crawl and grow, and the computer has to remember where each of its pieces is. That's what objects and arrays are for.

In this lesson you will:
  • describe the apple with an object { x: 15, y: 10 };
  • describe the snake with an array — a list of pieces;
  • draw the whole snake with a loop;
  • write a draw function that draws the whole game.

An object is a box with compartments

An apple has two numbers: x and y. You could make two variables, appleX and appleY, but it's handier to put them in one box with compartments. A box like that is called an object:

let apple = { x: 15, y: 10 };

An object is written in curly brackets. Inside are its properties: a name, a colon, a value. Properties are separated by commas. You get a value out with a dot:

console.log(apple.x);   // 15
console.log(apple.y);   // 10
apple.x = 3;            // moved the apple

You've seen a dot like this before: ctx.fillStyle, console.log. Those are objects with properties too!

An array is a list

An array is a list where values stand in order. It's written in square brackets:

let colors = ["red", "green", "blue"];
console.log(colors[0]);       // red
console.log(colors[2]);       // blue
console.log(colors.length);   // 3
  • Every place in the list has a number. It's called an index.
  • Numbering starts from zero! The first element is colors[0], the second is colors[1].
  • colors.length is the length of the list — how many elements it has.
⚠️ The last element If a list has 3 elements, their numbers are 0, 1, 2. There's no element number 3: colors[3] gives undefined ("not defined"). The last element always has the number length - 1.

The snake is a list of pieces

Each piece of the snake is a cell with x and y coordinates — that is, an object. And the whole snake is a list of such objects. The first one in the list (number 0) will always be the head:

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];

How do you get the head's coordinates? First take the list element, then its property: snake[0].x is 10, snake[2].x is 8.

Drawing the whole snake with a loop

The loop goes through all the pieces with numbers from 0 to snake.length - 1 and draws each one:

for (let i = 0; i < snake.length; i++) {
  drawCell(snake[i].x, snake[i].y, "lime");
}

However many pieces the snake has — 3 or 300 — this loop will draw them all.

The draw function

Let's collect all the drawing into one function, draw: clear the field, draw the apple and the snake. We'll draw the head in yellow on top of the green piece, so you can see which way the snake is facing. Rewrite the script like this (new lines are green, lines to delete are red):

let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
let size = 20;
let cells = 20;

let snake = [
  { x: 10, y: 10 },
  { x: 9, y: 10 },
  { x: 8, y: 10 }
];
let apple = { x: 15, y: 10 };

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

function draw() {
  clearField();
  drawCell(apple.x, apple.y, "red");
  for (let i = 0; i < snake.length; i++) {
    drawCell(snake[i].x, snake[i].y, "lime");
  }
  drawCell(snake[0].x, snake[0].y, "yellow");
}

clearField();
drawCell(10, 10, "lime");
drawCell(9, 10, "lime");
drawCell(8, 10, "lime");
drawCell(15, 10, "red");
draw();
💡 Order in a program At the top — variables (what we remember), in the middle — functions (what we can do), at the bottom — calls (what we do right now). This order helps you not get lost when the program gets long.

A console trick

You can change the program's variables straight from the console! Open it (F12) and type these one at a time, pressing Enter after each line:

snake.push({ x: 7, y: 10 });
draw();

The snake got longer! The push command adds a new element to the end of the list. Try some more:

snake.length
apple.x = 2;
draw();

If you refresh the page (F5), everything goes back to how it was: the program starts again from the beginning.
