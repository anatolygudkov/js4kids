The apple and growing

The snake crawls right through the apple without even noticing it. Let's teach it to eat! Eat an apple — grow by one piece, get a point, and a new apple appears in a random place.

In this lesson you will:
  • get random numbers with Math.random and Math.floor;
  • write a function that returns an answer (return);
  • teach the snake to eat and grow;
  • show the score on the page.

Random numbers

Open the console and type this several times:

Math.random()

Each time you get a new decimal number from 0 to 1 (but never exactly 1): 0.7364…, 0.0912…. Math is a set of maths commands built into JavaScript, and random means "chosen by chance".

But we need a cell from 0 to 19. We'll do it in two steps:

  1. Math.random() * 20 — a random number from 0 to 19.999…;
  2. Math.floor(...) — chop off the decimal part (floor: round down). 13.82 becomes 13.
Math.floor(Math.random() * 20)

Repeat this in the console many times: you'll get whole numbers from 0 to 19, like a dice with twenty sides.

A function that answers

Our functions so far have done something: drawn, moved. But there are also functions that answer — they return a result. For that there's the word return:

function randomCell() {
  return Math.floor(Math.random() * cells);
}

Now you can write randomCell() wherever you need a random number: apple.x = randomCell(); — and the function's answer goes into apple.x. Just like prompt returned what the person typed.

The snake eats

How do we know the snake has eaten the apple? Its new head is on the same cell as the apple: both x and y match.

if (head.x === apple.x && head.y === apple.y) {

And now the trick. Remember the experiment in lesson 8, when we removed snake.pop() and the snake grew? We'll do exactly that: if the snake has eaten the apple, we don't remove the tail. The head was added, the tail stayed, and the snake is one piece longer!

Changing the program

1. In the HTML, between the heading and the canvas, add a line with the score:

<h1>Snake</h1>
<p>Score: <span id="score">0</span></p>
<canvas id="game" width="400" height="400"></canvas>

<p> is a paragraph, and <span> is a little piece of text inside it. We gave it the name id="score" so that we can find it from JavaScript and change the number.

2. Add a variable for the score after dx and dy:

let dx = 1;
let dy = 0;
let score = 0;

3. Add the randomCell function after drawCell:

function randomCell() {
  return Math.floor(Math.random() * cells);
}

4. In the step function replace the line snake.pop(); with a check:

  snake.unshift(head);
  snake.pop();

  if (head.x === apple.x && head.y === apple.y) {
    score = score + 1;
    document.getElementById("score").textContent = score;
    apple.x = randomCell();
    apple.y = randomCell();
  } else {
    snake.pop();
  }

  draw();
}

Let's read it in plain English: "If the head is on the apple — add a point, show it on the page, move the apple to a random place. Otherwise — remove the tail."

document.getElementById("score") finds our <span> on the page, and .textContent = score changes the text inside it to the new number.

Save, refresh and try to catch the apple! 🍎

💡 Debugging with the console If something goes wrong, add a console.log in the right place, for example console.log("Yum! Score: " + score); inside the if. That way you can see whether the condition works. Once you've figured it out, delete that line.

📄 The whole snake.html file after this lesson 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Snake</title>
</head>
<body>
  <h1>Snake</h1>
  <p>Score: <span id="score">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake = [
      { x: 10, y: 10 },
      { x: 9, y: 10 },
      { x: 8, y: 10 }
    ];
    let apple = { x: 15, y: 10 };
    let dx = 1;
    let dy = 0;
    let score = 0;

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function draw() {
      clearField();
      drawCell(apple.x, apple.y, "red");
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function step() {
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x >= cells) {
        head.x = 0;
      }
      if (head.x < 0) {
        head.x = cells - 1;
      }
      if (head.y >= cells) {
        head.y = 0;
      }
      if (head.y < 0) {
        head.y = cells - 1;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        document.getElementById("score").textContent = score;
        apple.x = randomCell();
        apple.y = randomCell();
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        dx = 0;
        dy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        dx = 0;
        dy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        dx = -1;
        dy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        dx = 1;
        dy = 0;
      }
    }

    document.addEventListener("keydown", onKey);
    draw();
    setInterval(step, 200);
  </script>
</body>
</html>
