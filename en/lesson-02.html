The console and errors

Every programmer has a secret window where the program writes messages — the console. It's also where the computer tells you about errors. Today we'll make friends with it and stop being afraid of red messages.

In this lesson you will:
  • open the browser console;
  • learn to print text and numbers to it with console.log;
  • turn the computer into a calculator;
  • break the program on purpose and learn to read errors.

Opening the console

  1. Open your file test.html in Geany: File → Open (Ctrl + O) → the code folder. Even easier: File → Recent Files.
  2. Open the same file in the browser, like in the last lesson.
  3. In the browser press F12. A panel with developer tools appears on the right or at the bottom.
  4. At the top of the panel choose the Console tab.
💡 Shortcut In Firefox you can open the console directly with Ctrl + Shift + K. Press F12 again to close the panel.

Writing to the console

The alert window gets in the way: nothing happens until you click OK. That's why programmers write messages to the console with the command console.log (log means "write in the logbook"). Replace the line with alert with these:

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Test</title>
</head>
<body>
  <h1>My first program</h1>
  <script>
    console.log("Hello from the console!");
    console.log("I can count:");
    console.log(2 + 2);
  </script>
</body>
</html>

The new lines are marked in green. Save (Ctrl + S) and refresh the page (F5). Nothing new appears on the page itself, but the console shows:

Hello from the console!
I can count:
4

Look closely at console.log: there's a dot between console and log. It means "console, write this down!".

The calculator computer

Computers are great at maths. Here are the operation signs:

SignOperationExampleAnswer
+add7 + 512
-subtract7 - 52
*multiply (asterisk!)7 * 535
/divide (slash)10 / 42.5

Decimal numbers in programming are written with a dot: 2.5.

Try the difference between a number and text. Add this to the program:

console.log(2 + 2);
console.log("2 + 2");

The first line prints 4, the second prints 2 + 2. The computer doesn't calculate anything in quotes — it just shows it as it is. Programmers call text in quotes a string.

💡 The console can count too Click at the very bottom of the console, where the cursor blinks after the >> sign, type 7 * 8 and press Enter. The answer appears straight away. It's a handy way to try out small bits of code.

Break it and fix it

All programmers make mistakes, even the most experienced ones, many times a day. The main thing is learning to find them. Let's make a mistake on purpose.

Error 1: a typo in a command

Remove the letter e from one of the commands, so you get consol.log("Hello from the console!");. Save and refresh the page. A red message appears in the console:

❌ Uncaught ReferenceError: consol is not defined        test.html:10:5

Let's translate:

  • ReferenceError: consol is not defined — "Error: I don't know what consol is."
  • test.html:10:5 — the error is in the file test.html on line 10 (and 5 is the character number in that line). Look at the line numbers in Geany: the typo is right there on line ten!

Fix the typo, save and refresh: the error is gone.

⚠️ Notice After the error the program stopped: the lines below it didn't run either. That's why one tiny typo can "break" everything. Don't worry — fix it, and everything works again.

Error 2: a missing quote

Delete the closing quote: console.log("Hello from the console!);

❌ Uncaught SyntaxError: "" string literal contains an unescaped line break

SyntaxError means "a writing mistake", like a grammar mistake in a sentence. The computer is saying: "the text in quotes didn't end before the end of the line" — it couldn't tell where the text finishes.

Error 3: a missing bracket

Delete the closing bracket: console.log("Hello from the console!";

❌ Uncaught SyntaxError: missing ) after argument list

Here the computer says it straight out: missing ) — "a bracket ) is missing".

💡 Remember the task from lesson 1? alert(Hello); without quotes also gave an error: Hello is not defined. Without quotes the computer thinks Hello is the name of something it should know. With quotes it understands it's just text.
👨‍👩‍👧 For grown-ups Sometimes the console shows messages that have nothing to do with the child's code (from browser extensions, for example). Only look at the ones that mention our file: test.html, and later snake.html.
🎯 Tasks
  1. How many minutes are there in a day? Print 24 * 60 to the console.
  2. How many seconds are there in a day? (Hint: you can multiply three numbers.)
  3. Write console.log(10 - 3 * 2); and console.log((10 - 3) * 2);. Why are the answers different? (Just like in maths: brackets first, then multiplication.)
  4. Ask a friend or a grown-up to make one mistake in your code while you're not looking. Find it using the message in the console!
  5. ⭐ What does console.log("2" + "2"); print? Guess why.
