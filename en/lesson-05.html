Functions

Writing fillStyle and then fillRect with four numbers every single time is boring. Let's invent our own command, "draw a square". Home-made commands like this are called functions.

In this lesson you will:
  • divide the field into squares, like squared paper;
  • write the functions clearField and drawCell;
  • find out what function parameters are;
  • draw the snake using square numbers instead of pixels.
Lesson plan

A field made of squares

The snake crawls across squares (programmers call them cells). Our canvas is 400 by 400 pixels. If each cell is 20 pixels, a row holds 400 / 20 = 20 cells. Let's number them from zero: 0 to 19.

See the rule? Pixels = cell number × 20. Let the computer do that multiplication.

Your first function

A function is a recipe: we write down once what to do and give the recipe a name. After that, saying the name is enough, and the computer follows all the steps. Let's start with a simple recipe, "clear the field":

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}
  • function — "here comes a recipe";
  • clearField — its name;
  • () — the round brackets are required, even when empty;
  • between the curly brackets { } are the recipe's steps. They're indented so you can see they're inside.

A recipe that's only written down does nothing by itself. To make it work, you have to call it — write its name with brackets:

clearField();

You already know some functions invented by other people: alert(...), console.log(...), ctx.fillRect(...). Now you can make your own!

A function with parameters

To draw a cell, we need to know where and what colour. We pass this information to the function in the brackets. These are called parameters:

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

When we write drawCell(3, 2, "lime"), the function gets three boxes: x gets 3, y gets 2, and color gets "lime". Then it multiplies the cell numbers by the size size and draws.

💡 Why size - 1? The square comes out one pixel smaller than the cell, so a thin gap is left between neighbouring pieces. That way you can see which pieces the snake is made of. Later, try writing just size and compare.

Rewriting the game

Now replace the script in snake.html: the old lines with fillRect aren't needed any more.

💡 About indentation From now on the lessons often show only the piece of code that sits inside <script>, without the indent on the left. In your file these lines are moved to the right because they're inside the <script> tag. Leave them like that: indents don't matter to the computer, they're there to help people read the code. You can always see how everything looks together in the whole file at the end of the lesson. 
let canvas = document.getElementById("game");
let ctx = canvas.getContext("2d");
let size = 20;

function clearField() {
  ctx.fillStyle = "black";
  ctx.fillRect(0, 0, 400, 400);
}

function drawCell(x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(x * size, y * size, size - 1, size - 1);
}

clearField();
drawCell(10, 10, "lime");
drawCell(9, 10, "lime");
drawCell(8, 10, "lime");
drawCell(15, 10, "red");

Save and refresh. A snake of three pieces is facing right, and there's an apple in front of it. Notice how easy it is to move the pieces now: change the cell number and that's it.

⚠️ Common mistakes
  • A missing closing curly bracket }: you'll get the error missing } after function body — "a } is missing after the function's body".
  • The function is called, but its name is spelled differently (drawcell instead of drawCell): the error is drawcell is not defined.
🎯 Tasks
  1. Draw the first letter of your name out of cells.
  2. Put an apple in each of the four corners of the field. What are the numbers of the corner cells? (Hint: the last cell is 19, not 20.)
  3. Make the snake's head a different colour, for example "yellow".
  4. ⭐ Write a function drawApple(x, y) that draws a red cell. Inside, it can simply call drawCell!
When you're done, put the snake and the apple back like in the code above: the next lesson starts from it.
