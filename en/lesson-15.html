Making it pretty

The game is ready and working. Now for the fun part: let's dress it up! Web pages have a third language for how things look — CSS. We saved it for the end on purpose: first the program has to work, and then we decorate.

In this lesson you will:
  • find out what CSS is and where to write it;
  • change the background colour and fonts, and put a border around the field;
  • learn to pick elements by tag, by id and by class;
  • draw a round apple.

Three languages on one page

  • HTML — what is on the page (heading, score, field);
  • JavaScript — how it works (the snake crawls, eats, grows);
  • CSS — how it looks (colours, sizes, borders, fonts).

CSS is written inside a <style> tag, in the "head" of the page, in <head>. A CSS rule looks like this:

h1 {
  color: green;
  font-size: 48px;
}
  • h1 — who we're decorating (all <h1> headings). This is called a selector;
  • in the curly brackets — what we change: property, colon, value, semicolon.

Quite like objects in JavaScript, isn't it? Just with semicolons instead of commas.

Dressing up the page

Add a block of styles to <head>, after <title>:

<head>
  <meta charset="utf-8">
  <title>Snake</title>
  <style>
    body {
      background: #10241a;
      color: white;
      font-family: sans-serif;
      text-align: center;
    }
  </style>
</head>

Save and refresh: the background is dark green, the text is white, and everything is centred. Let's look at it:

PropertyWhat it changes
backgroundbackground colour
colortext colour
font-familyfont: sans-serif — without little "feet", serif — with them, monospace — like in a code editor
text-alignalignment: left, center, right
font-sizefont size, for example 48px

💡 Colour codes #10241a is a colour written as a code: after the hash come three pairs of symbols — how much red, green and blue the colour has. Each pair goes from 00 (none at all) to ff (the most). For example, #ff0000 is red, #ffff00 is yellow. You can also use names: green, gold, tomato.

The heading and the border

Add two more rules inside <style>, after the rule for body:

    h1 {
      color: #7ee081;
      font-size: 48px;
      margin: 10px;
    }
    canvas {
      border: 6px solid #3fa34d;
      border-radius: 10px;
    }

The score: selecting by id

To decorate one particular element, you select it by its id name with a # in front. Let's make the score and high score numbers yellow and bold:

    #score, #best {
      color: yellow;
      font-weight: bold;
    }

A comma between selectors means "this one and that one".

A hint: selecting by class

Add a hint for the player under the canvas. We'll give it a class — a name used for styling. Unlike an id, one class can be given to many elements.

<canvas id="game" width="400" height="400"></canvas>
<p class="help">Arrows - move, Space - new game</p>

In CSS a class is selected with a dot:

    .help {
      color: #9fb8a5;
    }
SelectorWhat it selectsExample
canvasall elements with that tag<canvas>
#scorethe one element with id="score"<span id="score">
.helpall elements with class="help"<p class="help">

A round apple

CSS doesn't decorate the canvas: JavaScript draws on it. Let's make the apple round. Add a function after drawCell:

function drawApple() {
  ctx.fillStyle = "red";
  ctx.beginPath();
  ctx.arc(apple.x * size + size / 2, apple.y * size + size / 2, size / 2 - 1, 0, Math.PI * 2);
  ctx.fill();
}
  • beginPath() — "I'm starting a new shape";
  • arc(x, y, radius, start, end) — an arc with its centre at point (x, y). The centre of a cell is its corner plus half its size. The radius is half a cell. And 0 and Math.PI * 2 mean "from the start to the end of the circle" — a full circle;
  • fill() — fill in the shape.

In the draw function, replace how the apple is drawn:

  drawCell(apple.x, apple.y, "red");
  drawApple();
🎯 Invent your own style
  1. Choose your own colours for the background, the heading and the border. You could make a "space" snake on a dark blue background or a "desert" one on sand colour.
  2. Change the snake's colours in draw and the field's colour in clearField so they go with the page.
  3. Give the heading a shadow: text-shadow: 3px 3px 0 black;
  4. ⭐ Draw eyes on the snake: two small black squares inside the head cell, after the head has been drawn.
📄 The finished game: the whole snake.html file 
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Snake</title>
  <style>
    body {
      background: #10241a;
      color: white;
      font-family: sans-serif;
      text-align: center;
    }
    h1 {
      color: #7ee081;
      font-size: 48px;
      margin: 10px;
    }
    canvas {
      border: 6px solid #3fa34d;
      border-radius: 10px;
    }
    #score, #best {
      color: yellow;
      font-weight: bold;
    }
    .help {
      color: #9fb8a5;
    }
  </style>
</head>
<body>
  <h1>Snake</h1>
  <p>Score: <span id="score">0</span> | Best: <span id="best">0</span></p>
  <canvas id="game" width="400" height="400"></canvas>
  <p class="help">Arrows - move, Space - new game</p>
  <script>
    let canvas = document.getElementById("game");
    let ctx = canvas.getContext("2d");
    let size = 20;
    let cells = 20;

    let snake;
    let apple = { x: 0, y: 0 };
    let dx;
    let dy;
    let nextDx;
    let nextDy;
    let score;
    let gameOver;
    let timer;
    let speed;
    let best = Number(localStorage.getItem("snakeBest"));

    function clearField() {
      ctx.fillStyle = "black";
      ctx.fillRect(0, 0, 400, 400);
    }

    function drawCell(x, y, color) {
      ctx.fillStyle = color;
      ctx.fillRect(x * size, y * size, size - 1, size - 1);
    }

    function drawApple() {
      ctx.fillStyle = "red";
      ctx.beginPath();
      ctx.arc(apple.x * size + size / 2, apple.y * size + size / 2, size / 2 - 1, 0, Math.PI * 2);
      ctx.fill();
    }

    function randomCell() {
      return Math.floor(Math.random() * cells);
    }

    function isOnSnake(x, y) {
      for (let i = 0; i < snake.length; i++) {
        if (snake[i].x === x && snake[i].y === y) {
          return true;
        }
      }
      return false;
    }

    function showScore() {
      document.getElementById("score").textContent = score;
      document.getElementById("best").textContent = best;
    }

    function placeApple() {
      apple.x = randomCell();
      apple.y = randomCell();
      while (isOnSnake(apple.x, apple.y)) {
        apple.x = randomCell();
        apple.y = randomCell();
      }
    }

    function draw() {
      clearField();
      drawApple();
      for (let i = 0; i < snake.length; i++) {
        drawCell(snake[i].x, snake[i].y, "lime");
      }
      drawCell(snake[0].x, snake[0].y, "yellow");
    }

    function endGame() {
      gameOver = true;
      clearInterval(timer);
      if (score > best) {
        best = score;
        localStorage.setItem("snakeBest", best);
        showScore();
      }
      ctx.fillStyle = "white";
      ctx.font = "32px sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("Game over", 200, 200);
      ctx.font = "18px sans-serif";
      ctx.fillText("Press Space to play again", 200, 240);
    }

    function step() {
      dx = nextDx;
      dy = nextDy;
      let head = { x: snake[0].x + dx, y: snake[0].y + dy };

      if (head.x < 0 || head.x >= cells || head.y < 0 || head.y >= cells) {
        endGame();
        return;
      }
      if (isOnSnake(head.x, head.y)) {
        endGame();
        return;
      }

      snake.unshift(head);

      if (head.x === apple.x && head.y === apple.y) {
        score = score + 1;
        showScore();
        placeApple();
        if (speed > 60) {
          speed = speed - 10;
          clearInterval(timer);
          timer = setInterval(step, speed);
        }
      } else {
        snake.pop();
      }

      draw();
    }

    function onKey(event) {
      if (event.key === "ArrowUp" && dy !== 1) {
        nextDx = 0;
        nextDy = -1;
      }
      if (event.key === "ArrowDown" && dy !== -1) {
        nextDx = 0;
        nextDy = 1;
      }
      if (event.key === "ArrowLeft" && dx !== 1) {
        nextDx = -1;
        nextDy = 0;
      }
      if (event.key === "ArrowRight" && dx !== -1) {
        nextDx = 1;
        nextDy = 0;
      }
      if (event.key === " " && gameOver) {
        startGame();
      }
    }

    function startGame() {
      snake = [
        { x: 10, y: 10 },
        { x: 9, y: 10 },
        { x: 8, y: 10 }
      ];
      dx = 1;
      dy = 0;
      nextDx = 1;
      nextDy = 0;
      score = 0;
      gameOver = false;
      speed = 200;
      showScore();
      placeApple();
      draw();
      timer = setInterval(step, speed);
    }

    document.addEventListener("keydown", onKey);
    startGame();
  </script>
</body>
</html>
🎉 The game is completely finished! You've written a real game: more than 150 lines of code in three languages. All that's left is to show it to the world.
